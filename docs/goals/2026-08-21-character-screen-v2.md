# Goal: キャラ画面 v2 — 入力の統一、効果の即時表示、人にやさしい設定

状態: 完了(2026-08-21、実機検証 docs/screenshots/20〜26)。ユーザーの実使用フィードバックに基づく。

## フィードバック(原文要約)

- 素ステがテキスト手入力で使いにくい。Stepper(±)も混在していて統一性がない
- 「キャラ一覧 | キャラデータ | 設定」の 3 列にして、バフを付けたときに値がどう変わるかをその場で見たい
- バフには初期値を入れておく(改・信頼の薬など)。イザベルの秘法と特選秘薬は別項目(特選は特別なときだけ)。クラブ効果は +7 固定
- キャラスキルは選択キャラで変わるので、キャラ別に表示を切り替えて ON/OFF
- 調整値は直感的に分かりづらい。「固定値を足す」と「能力値そのものを固定する」の意味が伝わる UI に
- 全体的に人にやさしくない

## 決定(ユーザー回答 2026-08-21)

- 数値入力は **「数値欄 + スライダー + MAX ボタン」の 1 部品**に統一(素ステ・ルーン・聖物・クラウン・手入力バフ・調整すべて)。Stepper は廃止
- 調整は残す。**「加算(+N)」と「能力値を固定(=N)」の 2 種**で、意味が伝わる名前・説明を付ける
- キャラスキルは **wiki 一覧にある全キャラ分**を取り込む

## 画面構成

```
┌ キャラ一覧 ─┐┌ キャラデータ ───────────────┐┌ 設定 ─────────────────┐
│ 登録(名前+種)││ 名前・キャラ種・覚醒/エタ        ││ [恒常補正] ペット/ルーン/ │
│ 一覧         ││ 能力値表: ステ | 素 | 補正 | 最終  ││   クラウン/聖物            │
│              ││   (設定を触ると即時に更新)         ││ [常用バフ] トグル+初期値    │
│              ││ 補正の内訳(開ける)               ││ [キャラスキル] キャラ別     │
│              ││                                  ││ [調整] 加算 / 固定         │
└──────────────┘└──────────────────────────────────┘└──────────────────────────┘
```

- **キャラデータ列が「答え」**: 素ステと最終能力値を常に並べて表示し、設定列を触るたびに(保存前でも)再計算して差分を見せる。計算は Rust(`preview_effective_stats` コマンド: base_stats + awakening + stat_sources → 最終能力値 + 寄与内訳)
- **設定列**はタブまたは折りたたみのグループ。1 グループずつ開く。保存はキャラ単位で 1 ボタン(未保存変更があるときだけ有効、「未保存」表示)
- **入力部品 `StatInput`**: ラベル | 数値欄 | スライダー | MAX。範囲は呼び出し側が渡す。素ステは 1–310、ルーン 0–20、聖物 0–40(表示は段階と +N 両方)、クラウン 0–300
- **バフ**: トグル(ON/OFF)+必要なら値。値は初期値入り(改・信頼 33、クラブ効果は +7 固定で値欄なし、イベントバフは段階選択)。イザベルの秘法と特選秘薬は別行(特選は下位に置き「特別な時のみ」の注記)。排他枠は同枠 ON で他を薄く表示+理由をツールチップ
- **キャラスキル**: 選択キャラのスキルだけを表示し ON/OFF。値は wiki 由来の固定値(段階があれば選択)。他キャラのスキルは表示しない
- **調整**: 「加算: このステに +N する(検証・仮定用)」「固定: 最終能力値を N に固定する(実測値で計算したい時)」。固定が設定されたステは能力値表で印を付ける
- 専門用語(固定値/最終固定値/倍率A/B)は設定列に出さない。内訳表示(キャラデータ列の「補正の内訳」)でのみ使う

## 受け入れ条件

1. Stepper と NumberField が消え、数値入力はすべて `StatInput` になっている
2. 設定列で値を変えると、保存前にキャラデータ列の最終能力値が即時に更新される
3. バフは初期値入りトグル。イザベル秘法/特選が別行、クラブ効果は値欄なし(+7)
4. キャラスキルが選択キャラごとに切り替わり ON/OFF できる(全キャラ分のカタログを gamedata に持つ)
5. 調整「加算」「固定」が意味の分かるラベルで動き、固定はトレースにも反映される
6. `cargo test --workspace`、`npm run build`、`npx svelte-check` 通過。実機スモークテストとスクリーンショット更新
7. docs(decisions / architecture / CLAUDE.md 現状)更新

## domain への影響

- `Adjustments` を「加算(fixed)」と「固定(override: Option<i64>)」に変更(final_fixed の調整は廃止)。override は `effective_stat` の結果を置き換え、トレースに `overridden` を残す
- `BuffCatalog` に `default_value`、`BuffTarget::CharacterSkill { game_character_id }` 相当のキャラ紐付け(または別カタログ `character_skill_buffs`)。値の層は wiki 調査結果に従う
- gamedata: プレイアブルキャラ全員を `characters` に追加(スキルデータはボリス以外空でよい)

## スコープ外

- 装備・属性・モンスターカード
- 計算画面の再設計(一時調整の文言だけ本 goal と揃える)
