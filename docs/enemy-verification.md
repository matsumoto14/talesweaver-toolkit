# 敵ステータスの実測検証

敵の値はゲーム内で見られない。wiki の狩り場情報一覧が唯一の出典だが、`約` / `推定値` と
書かれた行があり、収録側でも `[仮]` を付けている(値の一覧と実装状況は
[docs/damage-formula.md §11](damage-formula.md)、収録先は `crates/gamedata/src/enemies.rs`)。

ここは **自分側を既知にして、実測ダメージから敵側を逆算する** 手順をまとめたもの。
逆算した値で `[仮]` を置き換えていく。

## なぜ逆算できるか

敵側の 4 つは与ダメージ式での効き方が違う。

| 記号 | 敵側の値 | 効き方 |
|---|---|---|
| C | 防御力 | 引き算(掛け算の前) |
| V1 | カット率A | 掛け算 |
| V2 | カット率B(コンテンツ別) | 掛け算 |
| M | 被害減少 | 引き算(掛け算のあと) |

攻撃側の値 `x` を変えたときのダメージは `y = (x − C) × K − M`(`K` はカット率の積)という
**直線**になる。だから 2 点測れば傾き `K` と切片が出る。切片には `C × K + M` がまとまって
入るので、C と M を分けるにはもう 1 条件要る(下の手順 3)。

## 手順

### 1. 先に式を信用できる状態にする

wiki に全項目そろっている敵(訓練用トゥタトゥールなど)で、ツールの計算値と実測が合うか見る。
**ここがズレるなら敵の値ではなく自分側か式の問題**なので、敵の逆算に進まない。
「なぜこの数字?」の内訳を開いて、攻撃力・スキル倍率・属性差・クリ倍率が想定どおりか確かめる。

### 2. カット率の積(K)を出す

同じスキル・同じ属性で、**装備を替えて攻撃力を 2 段階**にし、それぞれ 10 発ほど撃って
**非クリティカルの最大値**を採る(表示は min〜max の幅があるので、必ず同じ側を採る)。

```
K = (y2 − y1) / (x2 − x1)
```

`x` はツールが出す「攻撃力(A)」ではなく、**カット率の直前まで積み上げた値**を使う。
計算タブの内訳(なぜこの数字?)にその段が出ている。

### 3. 防御力(C)と被害減少(M)を分ける

切片は `C × K + M` なので、2 点測定だけでは分けられない。**ペットの強打**(確率で防御力を
一定割合無視。極限後は −50%)が乗ったヒットと乗らないヒットの差が防御力ぶんそのものなので、
これで C を測り、残りを M にする。強打を持っていない場合は、C か M のどちらかを wiki 値で
固定して、もう一方だけを逆算する(どちらを固定したかを必ず記録する)。

### 4. クリティカル率(敵AGI・クリティカル被撃率)

同条件で 200 発ほど撃ち、クリティカルの回数を数える。実測クリ率を
[計算式まとめ #CriticalChance](https://talewiki.com/?%B7%D7%BB%BB%BC%B0%A4%DE%A4%C8%A4%E1) の式に
入れて逆算する。**AGI と被撃率は同じ式に入るので 1 回の測定では分けられない**。
AGI が wiki に載っている敵は被撃率だけを逆算する。

### 5. 属性値

属性強化を 1 ずつ上げながらダメージの増分を見る。差 1 あたり +0.625%、差 +80 で頭打ち(+50%)
なので、増分が止まる位置と自分の属性値から敵属性値が出る。

## 測定の注意

- **ダメージ上限に当たっていると直線が折れる**。上限手前で測る(内訳の「上限で捨てた分」が 0 か確認)
- **同じ側の値だけを採る**(非クリの最大値なら全部それ)。min と max を混ぜると傾きが狂う
- カット率は複数が乗算で入るので、**分離できるのは積まで**。V1 と V2 は分けられない
- 段数のあるスキルは 1 段ぶんに直してから比べる
- 実測は 1 回では足りない。同じ条件で 10 発以上を取り、外れ値(強打・特殊効果)を除く

## 記録の仕方

- 値は `crates/gamedata/src/enemies.rs` に入れ、**出典コメントを「実測(日付・条件)」に書き換える**。
  wiki 由来と実測由来が混ざるので、どちらか分かるようにしておく
- 逆算に使った条件(キャラ・スキル・装備・発数・生ダメージ)は、あとで再現できるように残す
- wiki 値と実測値が食い違ったときは **実測を採る**。wiki 側が「約」と書いている値ほど疑ってよい

## ツールでの支援

アプリの **実測** タブに、ゲームで出たダメージを条件つきで記録して送る画面がある。収録済みの敵なら
計算との差がその場で出る。測るときの武器はこの画面で切り替えられるので、キャラの登録を触らずに
攻撃力を変えた点を何点でも記録でき、2 点以上あれば上の手順 2〜3 の逆算(K と切片の分離)ができる。
送られた実測は問い合わせと同じ経路で GitHub Issue になり、`[仮]` の棚卸しに使う。
