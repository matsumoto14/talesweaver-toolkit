# ADR-011: ソウルリンク

- ステータス: 採用
- 日付: 2026-08-29
- 出典: Tale Wiki「ソウルリンク」`#linkstatus`（2026-08-29 取得）、[公式告知「ソウルリンクシステム改編」](https://talesweaver.nexon.co.jp/notice/notice.aspx?no=155029)（2026-06-17）

## 背景

リンクステータス1〜4は突き・斬り・魔攻・魔防へ Lv ごとに+2され、装備の基本能力値へ直接加算される。2026-06-17の公式改編で、5〜10はクリティカルダメージ、最終ダメージ、武器強化追加ダメージ、鎧強化追加HP、経験値、ELSO週間獲得上限へ対応した。

リンク枠や代表キャラクターを管理する必要はなく、戦闘力はキャラ単位で計算する。ソウルリンクの解放条件はすべて満たしている前提とする。

## 決定

- `SoulLinkStatus` はリンクステータス 1〜10 の現在 Lv をキャラの `StatSources` に持つ
- 対応は 1=突き、2=斬り、3=魔攻、4=魔防。各値は `Lv × 2`、Lv 上限は 25
- 加算先は `EquipmentValues` の**基本能力値**。装備のエンチャント/強化能力値には入れない
- 5はカテゴリGへ+1.5%/Lv（Lv20）、6はカテゴリLへ+4%/Lv（Lv5、既存上限45%）としてトレース付きで加算する
- 7は丸め済みの武器追加固定ダメージへ `TRUNC(base × (1 + Lv × 0.10))` を適用し、その後に既存のヒット分割を行う
- 8は鎧強化の追加HP（+5%/Lv）、9は経験値（+30%/Lv）、10はELSO週間獲得上限（+30,000/Lv）として保存・表示するが、現在の戦闘計算には接続しない
- 攻撃力、防御力、コンテンツ判定、詳細トレースのすべてで同じ基本能力値として消費する
- 条件達成済みのため、新規キャラと旧 JSON の欠落項目は各上限で補完する。画面では Lv0〜上限の段階入力として例外的に変更できる
- SQLite の列追加はせず、既存の `stat_sources` JSON に保存する
- 「ソウルリンクステータス（カテゴリーL）」手動バフは重複するためカタログから削除し、保存済みバフセットから冪等に除去する。「ソウルリンク探索（カテゴリーX2）」は別効果なので残す

## 対象外

- リンク枠、代表キャラクター、サブキャラクターの編成
- リンク人数、レベル、装備補正などの条件判定
- 戦闘力の合算やアカウント全体の値
- サブキャラクター向けのリンクステータス11〜15（コア転移）

## UI

キャラ画面の補正源「ソウルリンク」を「戦闘計算」と「記録のみ」に分ける。各行は現在 Lv、隣接する上限、Rustで計算した派生値を同じ視線上に置き、値が変わった派生値には短い bump を付ける。
