# ADR-013: Tale Wiki の取り込み

- ステータス: 採用(再配布の範囲は暫定。issue 参照)
- 期間: 2026-09-02
- 関連 issue: #14 構想、#15 境界、#16 app-api、#17 索引、#18 AI 相談、#28 段階 0〜2

## 背景

ゲーム仕様の一次ソースは Tale Wiki(EUC-JP の PukiWiki、3,443 ページ)。これまでは必要なページを
手作業のスクリプトで 1 本ずつ取り込んでおり、装備カタログ・称号・ランダム OP などは穴が多く、
神鳥の聖物・クラウン・カードなどは自由入力のまま(ux-guidelines 原則 1 に反する)。
wiki を丸ごと取り込む土台を作り、その上に既存の取込を載せ替える。

計測(2026-09-02): ページ数 3,443、うちドメイン外(Quest / Event / NPC / Shop / コメント等)約 1,500。
ソース総量 約 34 MB、取得 0.14 秒 / ページで全件 8 分。更新日時は `?cmd=rss` にあり `?cmd=list` には無い。

## 決定

### ゴール(4 つ)

1. **AI に聞ける**(#18): 「あのクエどう進める」に出典付きで答える。根拠は取り込んだ wiki だけ
2. **登録で選べる物を増やす**: 装備・神鳥・クラウン・ペット・カード等をカタログ化して自由入力をなくす
3. **キャラに紐づけた案内**: 登録キャラの Lv・装備・進行から「次に行けるクエ / ダンジョン」を出す
4. **見やすいミラー**: アプリ内で整形して読める。**元ページへの出典リンクを必ず付ける**

### 層

```
talewiki ──fetch──▶ [1] 生ミラー(page, source, mtime, rev)
                          │
            ┌─────────────┼──────────────────┐
            ▼             ▼                  ▼
   [2] 構造化抽出    [3] 索引(全文 + 意味)   [4] 整形表示(PukiWiki → HTML)
   gamedata の      サーバー。#17           ゴール 4。出典リンク付き
   Rust リテラル    ゴール 1 の根拠
   ゴール 2・3
```

- [1] は派生データの正本。gamedata の数値は [2] が [1] から生成する(手作業スクリプトを置き換える)。
  domain の正本はこれまでどおり gamedata / SQLite で、索引に置き換えない
- [2] だけがこのリポの中で完結する。[1][3][4] はサーバー(#15 の境界、#16 の基盤)を要る
- [1] の置き場はリポ外(スクラッチまたは `%APPDATA%`)の SQLite。差分は RSS + 週 1 の全件突き合わせ(改名・削除の検出)
- 取得は `.claude/skills/talewiki-fetch/scripts/fetch_page.py`(EUC-JP + NEC 拡張の復元)を土台にする

### 段階

各段が単独で価値を出し、次の段の土台になる順。

| 段階 | 内容 | 追跡 |
|---|---|---|
| 0 | 取込パイプライン `tools/gamedata/wiki/`(fetch_all → store → extract → gen_rust → diff)。既存 `import_*.py` を載せ替える | #28 |
| 1 | 既存スキーマの穴埋め(装備カタログ全件・称号・ランダム OP 非戦闘系・狩り場情報の未消費列・アナイスのマスタリー) | #28 |
| 2 | 自由入力のカタログ化(神鳥の聖物・クラウン・ペット・モンスターカード・消耗品・アビリティ全件・セット装備) | #28 |
| 3 | サーバーの索引と AI 相談 | #15 #16 #17 |
| 4 | キャラに紐づけた案内(Quest / Dungeon / Field の入場条件と敵情報を構造化、`contents.rs` を wiki 由来に) | — |
| 5 | 整形ミラー(PukiWiki 記法 → HTML) | — |

```
段階 0 ──▶ 段階 1 ──▶ 段階 2
   │
   └──▶ 段階 3(#15, #16, 再配布の決定) ──▶ 段階 5
   └──▶ 段階 4
```

段階 0〜2 はサーバー無しでリポの中だけで進む。そのあいだに #15 を書く。

### 再配布(暫定)

talewiki にライセンス表記が無い(2026-09-02 確認)。ゴール 4 と、ゴール 1 でサーバーが本文を持つことは
本文の再配布にあたる。ゴール 2・3 は数値・構造の抽出なので該当しない。

**サーバーは索引と断片だけ持つ**ところから始める(全文検索・意味検索の索引と、回答に引用する見出し +
数行の断片まで)。本文の閲覧は元ページへリンクし、ミラーは見出し・表の整形表示までに留める。
並行して管理者に許諾を打診し、取れれば全文へ広げる。索引は全文に昇格しても作り直しにならない。
打診の状況は issue で追う。

## 却下した選択肢

- 許諾なしで全文ミラー: 却下。再配布にあたる
- 索引をドメインの正本にする: 却下。計算の正本は gamedata / SQLite のまま(#17)
- 添付ファイルの丸ごと保存: 却下。画像はスキル・装備アイコンなど gamedata が使う分だけ
- コメント・wiki 編集・MenuBar 類の抽出: 却下。索引には入れるが抽出・案内には使わない

## 対象外

- 段階 3 以降のサーバー設計(#15 で決める)
