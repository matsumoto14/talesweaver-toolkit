# ADR-022: 表示言語(日本語 / 韓国語)

- ステータス: 採用
- 期間: 2026-09-24 〜
- 関連: ADR-012(ブラウザ版)、ADR-020(wiki に聞く)

## 背景

韓国のプレイヤーにも使ってもらうため、画面の文言とゲームデータ名(スキル・装備・バフ・敵・称号など)を
韓国語で出せるようにする(ユーザー判断 2026-09-24、デスクトップ版・ブラウザ版の両方)。
着手時点で文言はすべて日本語の直書きで、`t()` の外の日本語は画面側だけで約 2 万字(コメント除く)。
Rust もトレースの出どころ(「フルスロットル」)・部位名・エラー文を日本語で組み立てて返し、
画面はそれをそのまま出している。バフタブはトレースの出どころとバフ名を**文字列で**突き合わせている。

## 決定

1. **鍵は日本語の文言そのもの(gettext 方式)**。画面は `t("閉じる")` と書き、`apps/desktop/src/i18n/ko/*.json`
   (日本語 → 韓国語)を引く。辞書に無ければ日本語のまま出る。理由:
   - 日本語が正で、開発者も日本語で読む。`t("about.title")` のような鍵を挟むと画面のソースが読めなくなる
   - Rust が返す固定の表示名(部位名・出どころ名)も**同じ `t()` に通すだけ**で訳せる。Rust に言語を
     持ち込まず、突き合わせは日本語の元の文字列のまま行えるので、バフタブの文字列突き合わせも壊れない
   - 訳の漏れ・古い訳・`{name}` の穴の食い違いは `tools/i18n/check.py` が数える(型では守らない)
2. **言語はページを読み込むたびに 1 回だけ決まり、切り替えは読み込み直し**。labels.ts のように
   モジュール評価時に文言を作る所がそのまま効き、画面に言語の変化を追う仕掛けが要らない。
   切り替えは情報パネルの段(押した瞬間に読み込み直す)。選んだ言語は localStorage(`tw-locale`)。
   選んだことがなければ `navigator.language` が韓国語のときだけ韓国語
3. **辞書は出どころでファイルを分ける**。`ui.json`(画面の文言、Claude が訳して Codex がレビュー)・
   `terms.json`(画面が持つゲーム用語。韓国側の資料で裏取りする)・`rust.json`(Rust が返す表示名。
   `t(変数)` で引くので画面からは使用が見えず、未使用の点検から外す)・`names.json`(ゲームデータ名。
   韓国側の資料から取込で作る)
4. **Rust が文を組み立てて返すもの(エラー文・「武器を{}に更新」など)は、段階 2 で形のあるデータに変える**
   (コード + 引数を返し、文は画面が `t()` で作る)。固定の表示名はそのまま返してよい(決定 1)
5. **韓国語の辞書とフォントは韓国語のときだけ読む**(`loadLocale`)。ハングルは Noto Sans KR を
   日本語フォントの後ろに並べる(M PLUS はハングルを持たない)
6. **数値の書式は表示言語の Intl**(`LOCALE_TAG`)。書式の入口は format.ts だけ(R11)なので 1 か所
7. **ゲームデータ名の出どころ**: 装備は韓国コミュニティの装備整理シート(Google スプレッドシート
   `1rT24bRdfsqcX3N4JbRx1dZhqyEAf5OcAPnwPerd18Ds`、sacred_kr.rs と同じ出典)を名前で照合。
   キャラ・システム用語は韓国公式(tales.nexon.com)、敵・スキルは 나무위키 を当たる。ItemId を持つ
   韓国側データは見つかっていない
8. **「wiki に聞く」は対象外**。一次ソースの Tale Wiki が日本語だけで、答えも日本語の文面を引用する

## 段階

1. 土台: `i18n.ts`・言語の段・format.ts・labels.ts・情報パネル・点検スクリプト
2. Rust が組み立てる文をコード + 引数に
3. 画面の文言を `t()` に(ホーム → キャラ → 計算 → バフ → 残り)
4. ゲームデータ名(`names.json`)

## 却下した選択肢

- **i18n ライブラリ(paraglide-js / svelte-i18n / typesafe-i18n)**: 言語は 2 つで、切り替えは読み込み直し。
  必要なのは辞書を引く 1 関数だけで、コード生成やストアを足す理由が無い
- **意味の鍵(`about.title`)+ 型で漏れを防ぐ**: 画面のソースが読めなくなり、Rust の表示名を訳すには
  Rust 側にも鍵を持たせる必要がある。漏れの検出は点検スクリプトで足りる
- **Rust に言語を渡して Rust が訳す**: domain に表示の都合を持ち込む。訳は画面の仕事
- **切り替えをその場で反映(リアクティブ)**: 滅多に切り替えないものに、全画面の文言をリアクティブにする
  費用を払わない
