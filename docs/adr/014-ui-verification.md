# ADR-014: UI の検証方法

- ステータス: 採用
- 期間: 2026-09-16

## 背景

- 実機を自動で巡回して測る監査スクリプトが `tools/design-audit/live/` に 19 本あった(`playwright-core` + WebView2 の CDP 接続)。ソースを読む静的監査 `tools/design-audit/run.py`(R1〜R20)とは別系統。
- 19 本のうち 8 本が一度きりの調査の残骸だった。`round4` / `round5` / `round6` / `round9` / `round11` は「まだ一度も見ていない画面を見る」ための周回スクリプトで、その周が終われば再実行する意味がない。`sim10.js`(36 行・1 画面)は `motion.js`(158 行・網羅)の部分集合、`row.js` は 22 行でコメントも無かった。
- 同じ観点の世代が 3 つとも残っていた。スクリプト自身のコメントに記録がある — `clickall.js` は「`round4.js` は押すと**開く**ものしか測っていなかった」、`sweep.js` は「手書きのリストだと漏れる(12 周目のバフ、14 周目のシエナ)」、`overlay-bounds.js` は「`round4.js` は捕まえられない」。round4 → clickall → sweep の 3 世代が並存していた。
- **実害を事前に捕まえられていない。** `clickall.js` の追加理由は「エンチャント MAX で、押した行が一覧から消えて繰り上がった別の行を誤操作させた実害(2026-08)を監査が事前に捕まえられなかったため」。実害が出てから監査を足す後追いで、静的監査の R16(4 回書き直し)・R20(2 回書き直し)と同じ構造。
- `clickall.js` の `TARGETS` と `overlay-bounds.js` の `CASES` はタブ名と selector の手書きリストで、README 自身が「画面を足したらここにも足す。巡回に無い画面は永久に測られない」と書いていた。監査自体が「作り手に決めさせる」構造になっていた。
- `playwright-core` はリポの依存に無く、旧リポ `C:\github\private\twtoolkit`(非公開・別プロジェクト)の `node_modules` を `NODE_PATH` で借りて動かしていた。

## 決定

- **`tools/design-audit/live/` を全廃する**(19 本 + README)。実機を自動で巡回して測る監査は持たない。
- **UI が正しいかは人が決める。**起動して自分で押し、判断が要るものはスクリーンショットをユーザーに見せて決めてもらう(`design-review` skill の ②)。
- **`gui-smoke` skill は撮影専用にする。**自動操作・測定のヘルパー(`smoke-template.js`)を廃止し、`apps/desktop/scripts/shoot.js`(撮るだけ)に置き換える。`smoke-tester` agent は廃止(ADR-010 の「実機 GUI 確認は専任 agent に固定」を取り下げ)。
- **`playwright-core` は `apps/desktop` の devDependency にする。**撮影にのみ使い、旧リポからの借用をやめる。
- **静的監査 `run.py` に R21 以降を足さない。**規則が要るのは、まだ画面側に決めさせているからであり、規則ではなく部品側を直す。
- 開発 DB の保護(`db-guard.ps1` による前後の退避 / 復元)は**手で触るときも必ず通す**。自動操作をやめても、自動保存のキャラタブを手で押せば実データは壊れる。

## 理由

- 総当たり監査は予防になっていなかった(上記のとおり実害の後追い)。一方で保守コストは確実に発生していた — 残骸 8 本、世代重複 3 本、手書きリストの更新。
- **部品化が進むと、監査が見ている違反は書けなくなる。**「変わったのに跳ねない」は値を出す部品が保証し、「重なるものが画面外に開く」は `popover` 属性のトップレイヤーが保証する。監査を残す前提そのものが消える。
- 失うのは座標 1〜2px のズレの検出だけ。2026-09-16 に実測で見つかった 2 件(`<details>` の grid 方式が空振り・動きを消す設定で消えない経路)は、どちらも「動かない / 動いてしまう」なので目で分かる。
- 置換作業の検証は `grep` で 0 件を出せば足りる。動きが出るかは**部品 1 箇所を見れば全箇所に効く** — それが部品にする理由そのもの。

## 影響

- `docs/design-system.html` §14 の保留項目 H(`clickall.js` の ⚠ が 2 つの意味を持つ)は、スクリプトごと消えたので削除した。G(キャラタブが §09 規則 1 を一度も通していない)は残る — 着手条件を「使い捨てキャラ + `db-guard.ps1` で手で押す」に変えた。I(バフのチップ群の折り返し)は問題自体が実在するので残し、出典をスクリプトから 2026-09 の実測に改めた。
- `AGENTS.md` の §00 自己チェックから `motion.js` / `attention.js` を走らせる手順を外し、「起動して自分で押す」に変えた。
