# ダメージ計算・ステータス仕様(talewiki 整理)

出典: [Tale Wiki「ステータス」ページ](https://talewiki.com/?%A5%B9%A5%C6%A1%BC%A5%BF%A5%B9)(wiki 最終更新 2026-07-21、取得 2026-08-21)。
このドキュメントは wiki の記述を実装向けに構造化したもの。個別アイテム・スキルの数値カタログは静的データ(SQLite シード)として別管理し、ここには**計算モデルだけ**を書く。

## 1. ステータス(7種)

上限 1500(エタの意志で最大 2400)。下限 1。装備条件や一部スキルは素ステータス(オリジナル)を参照する。

- 出典: エタの意志ページ Lv100「最大ステータス開放」2,400(取得 2026-08-21)

| ステ | 主な効果 |
|---|---|
| STAB | 突き攻撃力の元。物理前ディレイ減少(武器ディレイ-1/5)、物理CI減少 |
| HACK | 斬り攻撃力の元。物理前ディレイ減少(-1/15)、物理CI減少 |
| INT | 魔法攻撃力の元。魔法クリティカル命中率上昇(対人のみ?) |
| DEF | 物理防御力+3、複合防御力+1.5、物理/複合カット率(プレイヤー)増加、スキルキャンセル率低下、物理回避+2/7、複合回避+1/7、HP自然回復+1/6 |
| MR | 魔法防御力+3、複合防御力+1.5、魔法/複合カット率増加、魔法回避+2/7、複合回避+1/7、MP自然回復+1/7、魔法前ディレイ減少(-1/5)、魔法CI減少、NOEFFECT/RECOVER率上昇、特殊回避+1/15 |
| DEX | 命中率+1、物理前ディレイ減少(-1/5)、物理CI減少、SP自然回復+1/7、攻撃力乱数部分に影響(§4 B) |
| AGI | 回避率+6/5、後ディレイ減少(-1/5)、クリティカル率増加/被クリ率減少、特殊回避+1/8 |

装備補正(装備S=突き、装備H=斬り、装備I=魔攻、装備F=物防、装備M=魔防、装備X=命中、C=クリ、装備A=回避、Q=敏捷)はステータスと別枠。防御はステ+3 に対し装備+6 と装備側が強い。

## 2. 能力値(実効ステータス)の計算

```
最終能力値 = 基本能力値 + [基本能力値 * 能力値倍率B] + 最終固定値増加/減少
基本能力値 = [(素ステータス + 割合増加(素ステ比) + 固定値増加/減少) * 能力値倍率A]
```

- `[]` 内は計算後小数点以下切り捨て
- 割合増加(素ステ比)は**バフごとに**切り捨ててから加算
- 能力値倍率A: 乗算で重なる(例: 退魔師の恵み 1.1倍)
- 能力値倍率B: 初期 0%、下限 -30%(デバフ側)
- 5 つのレイヤー(割合増加/固定値/倍率A/倍率B/最終固定値)それぞれにバフ・アイテムがぶら下がる。同名枠内は重複不可
- レイヤー別バフ一覧(常用バフ 16 件): wiki「ステータス」#jc16a054。カタログの実装は `crates/gamedata/src/buffs.rs`(型は `domain::stat_sources`)
- キャラスキル(自身/味方のステ上昇、9 件、`BuffGroup::CharacterSkill`/`AllySkill`)の一覧も同じ `crates/gamedata/src/buffs.rs` に置く。出典は各キャラの wiki `Skill/<キャラ>` ページ(docs/goals/2026-08-21-character-screen-v2.md「wiki 調査結果」参照。層の一部は `[仮]`)

## 3. 与ダメージ式(核心)

```
与ダメージ = [ ( ( MAX( (A + B − C) * {D*E1 + E2} * {F*G} * H * I * J * New1 + K, K )
                  * L * V1 + M )
                * Old * N * O * P * (1−Q) * R * (1−S) * T * (1−U) * (1−New2) * V2 + W )
              * X * Y ]

総与ダメージ = 与ダメージ * スキル段数 + 追加ダメージ各種
```

丸め・境界ルール:

- `[]` 内は計算後小数点以下切り捨て
- `{}` 内は小数第二位まで適用(第三位以下切り捨て)
- プレイヤーの被ダメージ ≦ 0 → Block。モンスターの被ダメージ ≦ 0 → 1
- K(最終ダメージ固定値)が入る時点で下限が K になる(MAX の意味)。K が無い場合は負値になり得る
- wiki 注記: 計算順序は確定ではない。丸め誤差が発生する場合あり
- 「与ダメージ」にはダメージ上限がある(覚醒・極限・エタの意志で変化)。「追加ダメージ」には上限がない(→ 武器強化の追加固定ダメージが与ダメージ式に含まれない理由)

種別の意味(カテゴリ共通ルール):

- **代入**: 計算結果・倍率をそのまま入れる
- **固定値**: 整数。初期値 0 に加減算
- **割合**: 百分率。初期値 100%(=1.0)に加減算し、計算時に小数へ
- **同一カテゴリ内は加算**(1.0 + 0.2 + 0.1 = 1.3。乗算ではない)。発生源が同じ枠内のものは重複不可

## 5. 追加ダメージ(与ダメージ式の外)

| 種別 | 算出基準 | 備考 |
|---|---|---|
| 武器強化 | 固定値 | `[数値 / スキル段数]` を段ごとに適用。PVP補正10% |
| 旧-割合 | 与ダメージ1段ごと | |
| 旧-割合(負荷軽減済み) | 合計ダメージ(=与ダメージ*段数) | カードスキル等。スキルごと上限3,000(例外あり) |
| 新-割合 | 合計ダメージ + 追加ダメージ(武器強化) | シャープネスビジョン、称号、武器ランダムOP等 |
| 固定値 | | スプラッシュ等 |

発生源ごとに丸め・表示が個別。適用可否:

| 攻撃種別 | 旧-割合 | 旧-割合(負荷軽減) | 新-割合 | 武器強化固定 |
|---|---|---|---|---|
| 通常攻撃 | ○ | ○ | ○ | ○ |
| スキル直接攻撃 | ○ | ○ | ○ | ○ |
| 状態異常 | × | × | ○ | × |
| 設置/陣/持続周辺 | × | × | ○ | ○(対象・使用ごと初回1ヒットのみ) |
| 武器強化固定ダメージ自体 | × | ○ | ○ | − |

見分け方: 中ディレイ開始時に表示=新、終了時に表示=旧。

## 6. 防御側の戦闘能力値

```
物理防御力 = [ [DEF * 3 + 装備物防 * 装備物理防御力倍率 * 6] * 物理ダメージ耐性(シエナ) ]
魔法防御力 = [ [MR * 3 + 装備魔防 * 装備魔法防御力倍率 * 6] * 魔法ダメージ耐性(シエナ) ]
複合防御力 = [ (DEF + MR) * 1.5 + (装備物防*物倍率 + 装備魔防*魔倍率) * 3 ]
```

- 装備防御力倍率は初期100%(コートアーマー物+18%/魔+12%、プロテクトアーマー物+36〜81%/魔+24〜54% 等)。リンゴの島・ベリネンルミでは常に100%
- 防御力には上限があり、覚醒/極限・エタの意志で上限増加。上限到達後の軽減はカット率(J)による
- この防御力は被ダメージ計算時のみ。該当能力値依存の攻撃力には影響しない

## 7. 命中・回避

- 命中率は下限 15%。表示値は同レベルモンスター相手の値で、実際はコンテンツごとに異なる(→ 計算式まとめ#HitRate、狩り場情報一覧 未取込)
- 回避は2種の合成: `最終被弾率 = (1 − 通常回避) × (1 − 特殊回避)`(例: 85% + 50% → 92.5%)
  - 通常回避: AGI 等で上昇。多段攻撃は1段ずつ判定。基本上限85%/下限0%
  - 特殊回避: コンボ・アイテム等(重複不可)。成功時は多段全段回避。回復魔法も回避対象
    - コンボ回避: `(10 + MR/15 + AGI/7.5)%`、下限20%/上限63%(係数は不正確の可能性と注記あり)
    - 最大63%系: `(40 + MR/15 + AGI/7.5)%`、下限40%/上限63%

## 8. 実装への示唆

- 計算パイプラインは「①能力値計算(§2) → ②カテゴリ集計(同一カテゴリ内は加算、キャップ適用) → ③与ダメージ式(§3、丸め順序込み) → ④段数・追加ダメージ(§5)」の4段
- 丸めの再現が正確性の肝: `[]`=floor、`{}`=小数2位切り捨て、割合増加はバフごとに floor
- バフ・アイテムは「カテゴリ + 数値 + 重複枠」を持つ静的データとしてモデル化する。UI もカテゴリ単位でバフを選ばせる構造が自然
- wiki 自身が「計算順序未確定・丸め誤差あり」としているため、検証値(実測ダメージ)との突き合わせ機能があると望ましい
- **入力最小化の観点(UX方針)**: 約30カテゴリのうちユーザーが都度入力すべきものはほぼ無い。A/B はキャラのステ・装備から、D/E/F はスキル選択から、C/V1/V2/M は敵(狩り場)選択から、L/N/O/P/X 等のバフはキャラに紐づくバフプリセットから自動で埋まる。つまり計算画面の入力は「キャラ・スキル・敵・バフセット」の4つの選択に還元できる。静的データの充実(§9 の未取込ページ)がそのまま入力削減になる
