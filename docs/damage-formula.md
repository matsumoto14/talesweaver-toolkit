# ダメージ計算・ステータス仕様(talewiki 整理)

出典: [Tale Wiki「ステータス」ページ](https://talewiki.com/?%A5%B9%A5%C6%A1%BC%A5%BF%A5%B9)(wiki 最終更新 2026-07-21、取得 2026-08-21)。
このドキュメントは wiki の記述を実装向けに構造化したもの。個別アイテム・スキルの数値カタログは静的データ(`crates/gamedata`)として別管理し、ここには**計算モデルだけ**を書く。

## 1. ステータス(7種)

上限 1500(エタの意志で最大 2400)。下限 1。装備条件や一部スキルは素ステータス(オリジナル)を参照する。

- 出典: エタの意志ページ Lv100「最大ステータス開放」2,400(取得 2026-08-21)

| ステ | 主な効果 |
|---|---|
| STAB | 突き攻撃力の元。物理前ディレイ減少(武器ディレイ-1/5)、物理CI減少 |
| HACK | 斬り攻撃力の元。物理前ディレイ減少(-1/15)、物理CI減少 |
| INT | 魔法攻撃力の元。魔法クリティカル命中率上昇(対人のみ?) |
| DEF | 物理防御力+3、複合防御力+1.5、物理/複合カット率(プレイヤー)増加、スキルキャンセル率低下、物理回避+2/7、複合回避+1/7、HP自然回復+1/6 |
| MR | 魔法防御力+3、複合防御力+1.5、魔法/複合カット率増加、魔法回避+2/7、複合回避+1/7、MP自然回復+1/7、魔法前ディレイ減少(-1/5)、魔法CI減少、NOEFFECT/RECOVER率上昇、特殊回避+1/15 |
| DEX | 命中率+1、物理前ディレイ減少(-1/5)、物理CI減少、SP自然回復+1/7、攻撃力乱数部分に影響(§4 B) |
| AGI | 回避率+6/5、後ディレイ減少(-1/5)、クリティカル率増加/被クリ率減少、特殊回避+1/8 |

装備補正(装備S=突き、装備H=斬り、装備I=魔攻、装備F=物防、装備M=魔防、装備X=命中、C=クリ、装備A=回避、Q=敏捷)はステータスと別枠。防御はステ+3 に対し装備+6 と装備側が強い。

## 2. 能力値(実効ステータス)の計算

```
最終能力値 = 基本能力値 + [基本能力値 * 能力値倍率B] + 最終固定値増加/減少
基本能力値 = [(素ステータス + 割合増加(素ステ比) + 固定値増加/減少) * 能力値倍率A]
```

- `[]` 内は計算後小数点以下切り捨て
- 割合増加(素ステ比)は**バフごとに**切り捨ててから加算
- 能力値倍率A: 乗算で重なる(例: 退魔師の恵み 1.1倍)
- 能力値倍率B: 初期 0%、下限 -30%(デバフ側)
- 5 つのレイヤー(割合増加/固定値/倍率A/倍率B/最終固定値)それぞれにバフ・アイテムがぶら下がる。同名枠内は重複不可
- レイヤー別バフ一覧(常用バフ 16 件): wiki「ステータス」#jc16a054。カタログの実装は `crates/gamedata/src/buffs.rs`(型は `domain::stat_sources`)
- キャラスキル(自身/味方のステ上昇、9 件、`BuffGroup::CharacterSkill`/`AllySkill`)の一覧も同じ `crates/gamedata/src/buffs.rs` に置く。出典は各キャラの wiki `Skill/<キャラ>` ページ(docs/claude/goals/2026-08-21-character-screen-v2.md「wiki 調査結果」参照。層の一部は `[仮]`)

## 3. 与ダメージ式(核心)

```
与ダメージ = [ ( ( MAX( (A + B − C) * {D*E1 + E2} * {F*G} * H * I * J * New1 + K, K )
                  * L * V1 + M )
                * Old * N * O * P * (1−Q) * R * (1−S) * T * (1−U) * (1−New2) * V2 + W )
              * X * Y ]

総与ダメージ = 与ダメージ * スキル段数 + 追加ダメージ各種
```

丸め・境界ルール:

- `[]` 内は計算後小数点以下切り捨て
- `{}` 内は小数第二位まで適用(第三位以下切り捨て)
- プレイヤーの被ダメージ ≦ 0 → Block。モンスターの被ダメージ ≦ 0 → 1
- K(最終ダメージ固定値)が入る時点で下限が K になる(MAX の意味)。K が無い場合は負値になり得る
- wiki 注記: 計算順序は確定ではない。丸め誤差が発生する場合あり
- 「与ダメージ」にはダメージ上限がある(覚醒・極限・エタの意志で変化)。「追加ダメージ」には上限がない(→ 武器強化の追加固定ダメージが与ダメージ式に含まれない理由)

種別の意味(カテゴリ共通ルール):

- **代入**: 計算結果・倍率をそのまま入れる
- **固定値**: 整数。初期値 0 に加減算
- **割合**: 百分率。初期値 100%(=1.0)に加減算し、計算時に小数へ
- **同一カテゴリ内は加算**(1.0 + 0.2 + 0.1 = 1.3。乗算ではない)。発生源が同じ枠内のものは重複不可

## 6. 防御側の戦闘能力値

```
物理防御力 = [ [DEF * 3 + 装備物防 * 装備物理防御力倍率 * 6] * 物理ダメージ耐性(シエナ) ]
魔法防御力 = [ [MR * 3 + 装備魔防 * 装備魔法防御力倍率 * 6] * 魔法ダメージ耐性(シエナ) ]
複合防御力 = [ (DEF + MR) * 1.5 + (装備物防*物倍率 + 装備魔防*魔倍率) * 3 ]
```

- 装備防御力倍率は初期100%。リンゴの島・ベリネンルミでは常に100%。増加手段(すべて共通スキル/バフ、出典 ステータス#Defense、取得 2026-08-25):

  | 名称 | 物理 | 魔法 |
  |---|---|---|
  | コートアーマー | +18% | +12% |
  | プロテクトアーマー | +36〜81% | +24〜54% |
  | 改・プロテクトアーマー | +9〜45% | +6〜30% |
  | 防御力増加(Cランク、水曜日の異変) | +10% | +10% |
  | プロテクトアーマーバフ(挑戦課題完了スタンプ) | +20% | +20% |
  | リリーローズの試薬(マインツ) | +10% | +10% |
  | シエナのオーラ「防御力増加」 | +x% | +x% |

- 防御力には上限があり、覚醒/極限・エタの意志で上限増加。上限到達後の軽減はカット率(J)による
- この防御力は被ダメージ計算時のみ。該当能力値依存の攻撃力には影響しない

## 7. 命中・回避

出典: 計算式まとめ `#HitRate` / `#AccuracyPoint` / `#EvasionPoint` / `#HitRateCap`、ステータス「命中率/回避率」(取得 2026-08-25)。

- `命中率 = 命中P − 対象の回避P`(パーセントポイント)
  - `命中P = [(DEX + 装備命中率補正 + (スキル命中 + 15) + 依存ボーナス − 依存ペナルティ + 命中P増加) × 命中P割合増加 × 命中P割合減少 + ランダムOP]`(実装済み。命中P増加・割合・ランダムOP はカタログに無く中立値)
    - wiki のスキル命中は実値から 15 引いた値が載っているため +15 する
    - 依存ボーナス/ペナルティは §4 A の依存表(例 STAB 依存: ボーナス `STAB×0.1` / ペナルティ `STAB/100`)
    - 命中P割合増加は集中(+5%)か的中剣(+35%)のどちらか一方、割合減少は感電/雷電(−30%)
  - `回避P = [15 + (AGI + 装備回避率) × 1.2 + 装備敏捷度/7 + 回避P増加 + 攻撃タイプに応じた回避P増加]`
    - 攻撃タイプ別増加(プレイヤーのみ): 物理 `(DEF×2 + [(STAB+HACK)/100])/7`、魔法 `(MR×2)/7`、複合 `(DEF+MR)/7`
    - モンスターの回避Pは `[15 + AGI×1.2]`(狩り場情報一覧)
  - 命中率下限 `= 15 + 攻撃者の最小命中率補正 − 対象の最小回避率補正`、上限はモンスターの攻撃 100 / プレイヤーの攻撃 `85 + 下限`
- 回避は2種の合成: `最終被弾率 = (1 − 通常回避) × (1 − 特殊回避)`(例: 85% + 50% → 92.5%)
  - 通常回避: `1 − 命中率/100` の裏返し。基本上限85%/下限0%。多段攻撃は1段ずつ判定
    - **「率」は出さない**(ユーザー決定 2026-08-25)。敵の命中Pが要り、その入力(狩り場情報一覧「上限回避P」)が全行未記載のため。画面には回避P(物理/魔法/複合)だけを出す
  - 特殊回避: コンボ・アイテム等(重複不可)。成功時は多段全段回避。回復魔法も回避対象
    - コンボ回避: `(10 + MR/15 + AGI/7.5)%`、下限20%/上限63%(係数は不正確の可能性と注記あり)
    - 最大63%系: `(40 + MR/15 + AGI/7.5)%`、下限40%/上限63%
- ステータス画面の命中率/回避率は**同レベルモンスター相手の値**で、実際はコンテンツごとに異なる
  - コンテンツ別の敵の強さは狩り場情報一覧の**必中命中P**(= 敵回避P + 100、攻撃側)と**上限回避P**(= 敵命中P − 15、防御側)
  - 必中命中Pは多くのコンテンツに値があるが、**上限回避Pは全行が未記載**。よって通常回避「率」はコンテンツを選んでも確定できない(2026-08-25 時点)

## 8. 属性

出典: 属性システム / 装備システム/属性強化 / 狩り場情報一覧(取得 2026-08-25)。

- 属性は 8 種(火・水・風・土・雷・白・黒・無)。キャラの属性値の上限は 255
- 与ダメージに効くのは**攻撃側の属性値 − 敵の属性値**の差だけ。差 +1 あたり +0.625%、+80 で上限 +50%。マイナス側の減少は無い(カテゴリI)
- 攻撃側の属性値 = **キャラの基礎属性値**(属性システムの各キャラ表で属性名に付く括弧の数値)+ **装備の属性強化**(1 部位 1 属性・0〜9。盾+(カフス)/レリックは対象外。無属性は付与できない)+ **装備以外の供給源**

  | 供給源 | 加算値 | 出典 |
  |---|---|---|
  | 装備の属性強化 | 10 部位 × 9 = 90 | wiki 装備システム/属性強化 |
  | ペット | +10 | ユーザー提供(2026-08-25) |
  | モンスターカード | +30 | 同上 |
  | ルーンスキル | +20 | 同上 |
  | 頭アビリティ | +20 | 同上 |
  | カフス(盾+)アビリティ | +30 | 同上(神秘鉱の鋭い刃 等) |

  合計 200 + キャラ基礎(最大 10)= 210。敵属性値 120 に対して属性差 +90 となり、上限の +80(= +50%)に届く
- スキルごとに属性が決まる(属性システム「スキル属性」)。表に載っていないスキルは属性差ボーナスなしとして扱う `[仮]`
- 敵の属性値は狩り場情報一覧の「敵属性値」。収録済みの 42 体は 120 / 125 / 90 の 3 値
- 攻撃側が「エレメンタルブレイク」を修得していると一定確率で防御側の属性値を 0 として計算する(未実装)

## 9. クリティカル率

出典: 計算式まとめ `#CriticalChance`、ステータス「ダメージ増加/減少カテゴリー」(取得 2026-08-25)。

```
クリティカル確率 = ( (装備クリティカル補正 + 1) × 2 × (AGI / (AGI + 対象のAGI))
                     × ペット会心 × シエナのオーラ
                     + スキルクリティカル率 + クリティカル率増加 + 対象のクリティカル被撃率A )
                   × 対象のクリティカル被撃率B + 最終クリティカル率増加
```

- 下限 0% / 上限 100%(余剰は意味なし)。クリティカル率増加は上限 +100%
- ペット会心 = ×1.1。vsモンスター/プレイヤー表記のものは上限の対象外
- **未実装**。式に要る入力のうち、対象のAGI・対象のクリティカル被撃率(狩り場情報一覧。多くの行が `?`)と**スキルクリティカル率**(スキルデータに無い)が揃わない。装備クリティカル補正は段階2 で入った
- クリティカル率自体は与ダメージ式に入らない(入るのは F: Cri倍率 と G: クリティカルダメージ増加)

## 10. 覚醒・エタの意志で開放される上限

出典: Quest/覚醒クエスト「各能力の上限値」「極限後の各値の増加効果」/ エタの意志「エタの成長」(Ver8.14、取得 2026-08-25)。

- **覚醒倍率(カテゴリN)** は「二次極限+N次覚醒」の覚醒ダメージ: 2次 +20% / 3次 +40% / 4次 +60% / 5次 +100%(= ×1.2 / 1.4 / 1.6 / 2.0)
  - 5次覚醒のあとはエタの意志 Lv で伸びる。倍率 = `1.0 + 覚醒ダメージ% / 100`(Lv0 = 100% → 2.00、Lv100 = 159% → 2.59)
- **ダメージ上限**は**多段スキルでも 1 段ごとに適用**される

  | 段階 | ダメージ | 防御力 |
  |---|---|---|
  | 初期値 | 7,000 | 4,300 |
  | 1次覚醒 | 9,999 | 6,100 |
  | 2次覚醒 | 12,000 | 7,900 |
  | 3次覚醒 | 15,000 | 9,700 |
  | 4次覚醒 | 18,000 | 9,700 |
  | 一次極限 | 999,999 | 9,700 |
  | 二次極限 | 3,000,000 | 12,000 |

- エタの意志 Lv1〜100 で「最大ダメージ / 最大HP / 最大防御力 / 最大ステータス」が伸びる(Lv100 = 29,500,000 / 4,100,000 / 24,000 / 2,400)
- **最終能力値の上限 2,400** はエタの意志 Lv100 の「最大ステータス開放」。素の上限は 1,500(ステータス ページ)
- 防御力は上限に届いたあと頭打ちになり、そこから先の軽減はカット率 J が担う(§6)

## 12. 実装への示唆

- 計算パイプラインは「①能力値計算(§2) → ②カテゴリ集計(同一カテゴリ内は加算、キャップ適用) → ③与ダメージ式(§3、丸め順序込み) → ④段数・追加ダメージ(§5)」の4段
- 丸めの再現が正確性の肝: `[]`=floor、`{}`=小数2位切り捨て、割合増加はバフごとに floor
- バフ・アイテムは「カテゴリ + 数値 + 重複枠」を持つ静的データとしてモデル化する。UI もカテゴリ単位でバフを選ばせる構造が自然
- wiki 自身が「計算順序未確定・丸め誤差あり」としているため、検証値(実測ダメージ)との突き合わせ機能があると望ましい
- **入力最小化の観点(UX方針)**: 約30カテゴリのうちユーザーが都度入力すべきものはほぼ無い。A/B はキャラのステ・装備から、D/E/F はスキル選択から、C/V1/V2/M は敵(狩り場)選択から、L/N/O/P/X 等のバフはキャラに紐づくバフプリセットから自動で埋まる。つまり計算画面の入力は「キャラ・スキル・敵・バフセット」の4つの選択に還元できる。静的データの充実(§9 の未取込ページ)がそのまま入力削減になる
