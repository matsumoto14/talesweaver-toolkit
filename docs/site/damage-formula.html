1. ステータス(7種)

上限 1500(エタの意志で最大 2400)。下限 1。装備条件や一部スキルは素ステータス(オリジナル)を参照する。

  • 出典: エタの意志ページ Lv100「最大ステータス開放」2,400(取得 2026-08-21)
ステ 主な効果
STAB 突き攻撃力の元。物理前ディレイ減少(武器ディレイ-1/5)、物理CI減少
HACK 斬り攻撃力の元。物理前ディレイ減少(-1/15)、物理CI減少
INT 魔法攻撃力の元。魔法クリティカル命中率上昇(対人のみ?)
DEF 物理防御力+3、複合防御力+1.5、物理/複合カット率(プレイヤー)増加、スキルキャンセル率低下、物理回避+2/7、複合回避+1/7、HP自然回復+1/6
MR 魔法防御力+3、複合防御力+1.5、魔法/複合カット率増加、魔法回避+2/7、複合回避+1/7、MP自然回復+1/7、魔法前ディレイ減少(-1/5)、魔法CI減少、NOEFFECT/RECOVER率上昇、特殊回避+1/15
DEX 命中率+1、物理前ディレイ減少(-1/5)、物理CI減少、SP自然回復+1/7、攻撃力乱数部分に影響(§4 B)
AGI 回避率+6/5、後ディレイ減少(-1/5)、クリティカル率増加/被クリ率減少、特殊回避+1/8

装備補正(装備S=突き、装備H=斬り、装備I=魔攻、装備F=物防、装備M=魔防、装備X=命中、C=クリ、装備A=回避、Q=敏捷)はステータスと別枠。防御はステ+3 に対し装備+6 と装備側が強い。

2. 能力値(実効ステータス)の計算

最終能力値 = 基本能力値 + [基本能力値 * 能力値倍率B] + 最終固定値増加/減少
基本能力値 = [(素ステータス + 割合増加(素ステ比) + 固定値増加/減少) * 能力値倍率A]
  • [] 内は計算後小数点以下切り捨て
  • 割合増加(素ステ比)はバフごとに切り捨ててから加算
  • 能力値倍率A: 乗算で重なる(例: 退魔師の恵み 1.1倍)
  • 能力値倍率B: 初期 0%、下限 -30%(デバフ側)
  • 5 つのレイヤー(割合増加/固定値/倍率A/倍率B/最終固定値)それぞれにバフ・アイテムがぶら下がる。同名枠内は重複不可
  • レイヤー別バフ一覧(常用バフ 16 件): wiki「ステータス」#jc16a054。カタログの実装は crates/gamedata/src/buffs.rs(型は domain::stat_sources)
  • キャラスキル(自身/味方のステ上昇、9 件、BuffGroup::CharacterSkill/AllySkill)の一覧も同じ crates/gamedata/src/buffs.rs に置く。出典は各キャラの wiki Skill/<キャラ> ページ(docs/claude/goals/2026-08-21-character-screen-v2.md「wiki 調査結果」参照。層の一部は 仮)

3. 与ダメージ式(核心)

与ダメージ = [ ( ( MAX( (A + B − C) * {D*E1 + E2} * {F*G} * H * I * J * New1 + K, K )
                  * L * V1 + M )
                * Old * N * O * P * (1−Q) * R * (1−S) * T * (1−U) * (1−New2) * V2 + W )
              * X * Y ]

総与ダメージ = 与ダメージ * スキル段数 + 追加ダメージ各種

丸め・境界ルール:

  • [] 内は計算後小数点以下切り捨て
  • {} 内は小数第二位まで適用(第三位以下切り捨て)
  • プレイヤーの被ダメージ ≦ 0 → Block。モンスターの被ダメージ ≦ 0 → 1
  • K(最終ダメージ固定値)が入る時点で下限が K になる(MAX の意味)。K が無い場合は負値になり得る
  • wiki 注記: 計算順序は確定ではない。丸め誤差が発生する場合あり
  • 「与ダメージ」にはダメージ上限がある(覚醒・極限・エタの意志で変化)。「追加ダメージ」には上限がない(→ 武器強化の追加固定ダメージが与ダメージ式に含まれない理由)

種別の意味(カテゴリ共通ルール):

  • 代入: 計算結果・倍率をそのまま入れる
  • 固定値: 整数。初期値 0 に加減算
  • 割合: 百分率。初期値 100%(=1.0)に加減算し、計算時に小数へ
  • 同一カテゴリ内は加算(1.0 + 0.2 + 0.1 = 1.3。乗算ではない)。発生源が同じ枠内のものは重複不可

4. カテゴリー一覧

記号 名称 種別 範囲・上限 備考
A 攻撃力 代入 [ステ攻撃力 + 装備攻撃力] + [装備攻撃力/25 * 装備攻撃力強化倍率] * 25。ステ攻撃力・装備攻撃力の係数はスキル依存種別(STAB/HACK/INT/MR/STAB+HACK/HACK+INT)ごとに wiki「計算式まとめ#BaseAttackPower」の表(取得 2026-08-22)で定義(crates/gamedata/src/characters.rs)。装備攻撃力は「基本能力値」(エンチャント除く素の装備補正・キャラスキル・アビリティ・称号)と「強化能力値」(エンチャント + シエナのオーラの能力値(武器/盾)+ テシスコアの火力タイプ補正)の 2 系統に分かれ、それぞれ別係数。テシスコアの能力値増加は対象ダンジョン内でのみ有効なので、強化能力値の集計は計算対象コンテンツの地域(Content::core_region)で変わる。テシスコアの補助タイプ(物防/回避/敏捷/命中)は与ダメージ式に入らないが、装備値の合計(Equipment::support_totals)としては保持する。装備攻撃力強化倍率 = パワーウェポン+2%(wiki Skill/共通)+ ストロングウェポン Lv×3%(Lv1〜6 = 3〜18%、同ページ)。どちらも共通スキルなので CommonSkills が持つ(ストロングウェポンの Lv2 以降はオーグメントの LvUp が前提)
B 攻撃力乱数部分 代入 最小1 最大 = {(ステ由来攻撃力 + DEX*3)/18} + 1
C 攻撃対象の防御力 固定値 敵データ。能力値減少デバフで低下。強打効果(確率で防御一定割合無視: ペット強打 7%/-100%(極限後-50%)、スキル強打 15%/-15% 等)は別枠
D スキル倍率 代入 スキルごと
E1 スキル倍率増加(割合) 割合
E2 スキル倍率増加(固定値) 代入 兜アビリティ等
F Cri倍率 代入 スキルごと。非クリティカル時は {F×G} ごと 1.0(G の供給源はすべて「クリティカルダメージ増加」で非クリには乗らない)
G クリティカルダメージ増加 割合 小数点以下切り捨て。極限スキル「スコープアイ」(基本+20% + スーパーリミット+3 + ハイパーリミット Lv1〜6 で +7〜+17 = 最大 +40%。wiki Skill/極限)
H コンボボーナス 割合 3コンボ以上で +15%
I 属性差ボーナス 割合 +0〜+50% 属性差1あたり +0.625%。小数点以下切捨、下限+0%
J カット率(プレイヤー) 割合 a = 3 + [(DEF+装備DEF−1)/10](物理)、MR版(魔法)、(DEF+装備DEF+MR+装備MR−1)/20(複合)。r = 1 − a/(a+80)
New1 攻撃力増加(シエナのオーラ) 割合 シエナのオーラの追加オプション「攻撃力増加」(1〜10%)。wiki「装備システム/シエナのオーラ#追加オプション一覧」に「実際は与ダメージ割合増加(新規カテゴリ)」と明記。同じ種類のオプションは同じ装備の別スロットに出ないため 1 部位 1 個、8 部位分が加算される(Equipment::siena_attack_rate)
K 最終ダメージ(固定値) 固定値 上限1000 テシスコアのセット効果(強化4のコアが 3〜5 個 / 6 個で進化段階に応じて +500〜+1,400。wiki「テシスコア#コアセット効果」)。セット効果は地域ごとに発動して重複するので 4 地域分が加算され、上限 1000 で頭打ちになる。式の下限も兼ねる
L 最終ダメージ 割合 上限+45% テシスコアのセット効果の上位段階(進化2の6セット〜進化4の6セットで +1〜+5%)。地域ごとに発動して重複するので最大 4 地域分が加算される(ThesisCores::set_bonus)
V1 カット率A 割合 モンスター素体ごとの設定
M 被害減少 固定値 鎧/盾/カフスアビリティ、敵側設定
Old 攻撃ダメージII 割合 初期100%、下限30%、上限300% 表記は「攻撃ダメージ(vsモンスター/プレイヤー)」
N 覚醒ダメージ 割合 覚醒・極限 +10〜100%、エタの意志
O 物理/魔法ダメージ増加 割合
P 特定依存ダメージ増加 割合 上限+73% STAB/STAB+HACK/HACK/HACK+INT/INT/MR 系統別。ランダムオプション「突き/斬り/物理複合/魔法/神聖/魔法斬り 攻撃力が X% 増加」(盾・レリック右)がここに入る。wiki 補足に「特定のスキルの与ダメージが X% 増加」とあり、スキルの依存種別が一致したときだけ乗る(Equipment::random_option_totals)
Q 物理/魔法ダメージ吸収 割合 +0〜+70% 式では (1−Q)。被ダメージ軽減
R 物理/魔法被ダメージ倍率 割合
S 被ダメージ減少 割合 サブカテゴリ合算: S1秘薬(上限+20%)、S2一般(+15%)、S3基本発動(+15%)、S4スキル(-30%〜+30%)、S5その他。式では (1−S)
T ダメージ増幅 割合 初期100%
U ダメージ耐性 割合 上限+62% 式では (1−U)。回復もカット。ダメージ上限・回復上限にも適用
New2 ダメージ緩和 割合 上限+40% 式では (1−New2)。ダメージ上限に適用、回復上限には非適用。計算タイミング未確定
V2 カット率B 割合 コンテンツごとの個別設定
W 攻撃ダメージ(基本発動)(固定値) 固定値 上限1000 武器/手アビリティ
X 攻撃ダメージ 割合 サブカテゴリ合算: X1イザベル(上限+50%)、X2一般(+30%)、X3基本発動(+80%)、X4スキル(+65%)、X5特殊(上限不明)、X6日本独自(+30%)。ランダムオプション「攻撃ダメージが X% 増加」(盾・レリック右)がここに入る
Y PVP補正 割合 5%(固定ダメージにも適用。追加ダメージ(武器強化)のみ 10%)

6. 防御側の戦闘能力値

物理防御力 = [ [DEF * 3 + 装備物防 * 装備物理防御力倍率 * 6] * 物理ダメージ耐性(シエナ) ]
魔法防御力 = [ [MR * 3 + 装備魔防 * 装備魔法防御力倍率 * 6] * 魔法ダメージ耐性(シエナ) ]
複合防御力 = [ (DEF + MR) * 1.5 + (装備物防*物倍率 + 装備魔防*魔倍率) * 3 ]
  • 装備防御力倍率は初期100%。リンゴの島・ベリネンルミでは常に100%。増加手段(すべて共通スキル/バフ、出典 ステータス#Defense、取得 2026-08-25):
名称 物理 魔法 実装
コートアーマー +18% +12% ✅ CommonSkills
プロテクトアーマー +36〜81% +24〜54% ✅ CommonSkills(Lv2 以降はオーグメントが前提)
改・プロテクトアーマー +9〜45% +6〜30% ✅ CommonSkills
シエナのオーラ「防御力増加」 +x% +x% ✅ Equipment::siena_defense_rate(1 部位 0〜10%)
防御力増加(Cランク、水曜日の異変) +10% +10% 未収録(期間限定)
プロテクトアーマーバフ(挑戦課題完了スタンプ) +20% +20% 未収録
リリーローズの試薬(マインツ) +10% +10% 未収録
  • 防御力には上限があり、覚醒/極限・エタの意志で上限増加。上限到達後の軽減はカット率(J)による
  • この防御力は被ダメージ計算時のみ。該当能力値依存の攻撃力には影響しない

7. 命中・回避

出典: 計算式まとめ #HitRate / #AccuracyPoint / #EvasionPoint / #HitRateCap、ステータス「命中率/回避率」(取得 2026-08-25)。

  • 命中率 = 命中P − 対象の回避P(パーセントポイント)
  • 命中P = [(DEX + 装備命中率補正 + (スキル命中 + 15) + 依存ボーナス − 依存ペナルティ + 命中P増加) × 命中P割合増加 × 命中P割合減少 + ランダムOP](実装済み。命中P増加・割合はカタログに無く中立値。ランダムOP は実装済み: 手・レリック左の「命中率が X 増加」)
    • wiki のスキル命中は実値から 15 引いた値が載っているため +15 する
    • 依存ボーナス/ペナルティは §4 A の依存表(例 STAB 依存: ボーナス STAB×0.1 / ペナルティ STAB/100)
    • 命中P割合増加は集中(+5%)か的中剣(+35%)のどちらか一方、割合減少は感電/雷電(−30%)
  • 回避P = [15 + (AGI + 装備回避率) × 1.2 + 装備敏捷度/7 + 回避P増加 + 攻撃タイプに応じた回避P増加]
    • 攻撃タイプ別増加(プレイヤーのみ): 物理 (DEF×2 + [(STAB+HACK)/100])/7、魔法 (MR×2)/7、複合 (DEF+MR)/7
    • 回避P増加にはランダムOP「回避率が X 増加」(手・レリック左)が入る(実装済み)
    • モンスターの回避Pは [15 + AGI×1.2](狩り場情報一覧)
  • 命中率下限 = 15 + 攻撃者の最小命中率補正 − 対象の最小回避率補正、上限はモンスターの攻撃 100 / プレイヤーの攻撃 85 + 下限
  • 回避は2種の合成: 最終被弾率 = (1 − 通常回避) × (1 − 特殊回避)(例: 85% + 50% → 92.5%)
  • 通常回避: 1 − 命中率/100 の裏返し。基本上限85%/下限0%。多段攻撃は1段ずつ判定
    • 「率」は出さない(ユーザー決定 2026-08-25)。敵の命中Pが要り、その入力(狩り場情報一覧「上限回避P」)が全行未記載のため。画面には回避P(物理/魔法/複合)だけを出す
  • 特殊回避: コンボ・アイテム等(重複不可)。成功時は多段全段回避。回復魔法も回避対象
    • コンボ回避: (10 + MR/15 + AGI/7.5)%、下限20%/上限63%(係数は不正確の可能性と注記あり)
    • 最大63%系: (40 + MR/15 + AGI/7.5)%、下限40%/上限63%
  • ステータス画面の命中率/回避率は同レベルモンスター相手の値で、実際はコンテンツごとに異なる
  • コンテンツ別の敵の強さは狩り場情報一覧の必中命中P(= 敵回避P + 100、攻撃側)と上限回避P(= 敵命中P − 15、防御側)
  • 必中命中Pは多くのコンテンツに値があるが、上限回避Pは全行が未記載。よって通常回避「率」はコンテンツを選んでも確定できない(2026-08-25 時点)

8. 属性

出典: 属性システム / 装備システム/属性強化 / 狩り場情報一覧(取得 2026-08-25)。

  • 属性は 8 種(火・水・風・土・雷・白・黒・無)。キャラの属性値の上限は 255
  • 与ダメージに効くのは攻撃側の属性値 − 敵の属性値の差だけ。差 +1 あたり +0.625%、+80 で上限 +50%。マイナス側の減少は無い(カテゴリI)
  • 攻撃側の属性値 = キャラの基礎属性値(属性システムの各キャラ表で属性名に付く括弧の数値)+ 装備の属性強化(1 部位 1 属性・0〜9。盾+(カフス)/レリックは対象外。無属性は付与できない)+ 装備以外の供給源
供給源 加算値 出典

9. クリティカル率

出典: 計算式まとめ #CriticalChance、ステータス「ダメージ増加/減少カテゴリー」(取得 2026-08-25)。

クリティカル確率 = ( (装備クリティカル補正 + 1) × 2 × (AGI / (AGI + 対象のAGI))
                     × ペット会心 × シエナのオーラ
                     + スキルクリティカル率 + クリティカル率増加 + 対象のクリティカル被撃率A )
                   × 対象のクリティカル被撃率B + 最終クリティカル率増加
  • 下限 0% / 上限 100%(余剰は意味なし)。クリティカル率増加は上限 +100%
  • ペット会心 = ×1.1。vsモンスター/プレイヤー表記のものは上限の対象外
  • 実装済み(crates/domain/src/critical_rate.rs)。対象のAGI と 対象のクリティカル被撃率が両方そろっている敵でだけ出す
  • 狩り場情報一覧は多くの行が ?。被撃率は −250〜−930% と支配的なので、片方だけで出すと桁違いに外れる
  • 値が入っているのは 11 体(オーディン / エクリプス 1・2・討伐戦 / 異界の峡谷 部隊長 / 最後の決戦3 / アフェティリア(N) / セリニアコス(H) / キシニク(H) / レリックの聖域20 / レイティアH)。 AGI だけの敵(アビスヘル 等)は AGI を持つが率は出さない
  • スキルの Cri値(Skill::critical_rate)は S5 で収録済み。wiki が - の 28 件では出さない
  • クリティカル率増加(上限 +100%)は値が確定している 3 件だけ収録: 極のルーン +20 / 設計者の研究室 +30 / 致命打 +100。 値が n の「バフ」、シエナのオーラのクリティカル確率、被撃率B(対人)、最終クリティカル率増加は未収録(中立値)
  • 敵の値は「約」「推定値」付きのコミュニティ実測なので 仮
  • エクリプスより下の低レベル帯のクリティカルは考慮しない(ユーザー決定 2026-08-25)。 wiki が ? の行はそのまま未収録でよい
  • クリティカル率自体は与ダメージ式に入らない(入るのは F: Cri倍率 と G: クリティカルダメージ増加)

10. 覚醒・エタの意志で開放される上限

出典: Quest/覚醒クエスト「各能力の上限値」「極限後の各値の増加効果」/ エタの意志「エタの成長」(Ver8.14、取得 2026-08-25)。

  • 覚醒倍率(カテゴリN) は「二次極限+N次覚醒」の覚醒ダメージ: 2次 +20% / 3次 +40% / 4次 +60% / 5次 +100%(= ×1.2 / 1.4 / 1.6 / 2.0)
  • 5次覚醒のあとはエタの意志 Lv で伸びる。倍率 = 1.0 + 覚醒ダメージ% / 100(Lv0 = 100% → 2.00、Lv100 = 159% → 2.59)
  • ダメージ上限は多段スキルでも 1 段ごとに適用される
段階 ダメージ 防御力
初期値 7,000 4,300
1次覚醒 9,999 6,100
2次覚醒 12,000 7,900
3次覚醒 15,000 9,700
4次覚醒 18,000 9,700
一次極限 999,999 9,700
二次極限 3,000,000 12,000
  • エタの意志 Lv1〜100 で「最大ダメージ / 最大HP / 最大防御力 / 最大ステータス」が伸びる(Lv100 = 29,500,000 / 4,100,000 / 24,000 / 2,400)
  • 最終能力値の上限 2,400 はエタの意志 Lv100 の「最大ステータス開放」。素の上限は 1,500(ステータス ページ)。 実装済み(effective_stat が cap を受け取る)。上限に当たった分は StatTrace::capped_loss に残す。 調整の「固定(pin)」は上限のあとに適用する(実測値をそのまま入れるための例外操作なので上限で削らない)
  • 防御力は上限に届いたあと頭打ちになり、そこから先の軽減はカット率 J が担う(§6)

12. 中ディレイ(スキルの発動間隔)

出典: 計算式まとめ #ActualDelay / ステータス「中ディレイ倍率A / 倍率B」/ 各キャラの スキル性能一覧「動作」列(取得 2026-08-25)。

中ディレイ = 基本中ディレイ × (1 − 中ディレイ減少値) × (2 コンボ以上なら 0.5)   (下限 0.3s)
  • 基本中ディレイは wiki スキル性能一覧の「動作」列。303 件すべて取り込み済み(Skill::base_actual_delay)
  • A/B 表記(イェフネンのパイク系)は条件付き([加速])なので基本値の A を採る
  • (固定) 付き(ティチエル 極・ギガブレイズ / クロエ 極・メテオストライク)は中ディレイ減少が効かない
  • 秒として読めない 1 件(ティチエル 極・スパークリングカイト。wiki 表記が 0)は None = 中ディレイ・DPS を出さない
  • チャネリングスキル(区分 続)の「動作」はチャネリング全体の秒数(例: 極・連撃 10s)。 2025/10/29 から全てのチャネリングスキルに中ディレイ減少が適用される(コンボボーナス除く)
  • 中ディレイ減少値(= 倍率B の減少分)は上限 70%(倍率B の下限 30%)。供給源(ステータス「中ディレイ倍率B」の表):
供給源 減少 実装
極限スキル フルスロットル −25〜−45% ✅ UltimateSkills::actual_delay_reduction
カフス(盾+)のランダムオプション −1〜−3% ✅ RandomOptionEffect::ActualDelayReduction
シエナのオーラ 追加オプション −x%(1 部位 0〜2%) ✅ Equipment::siena_actual_delay_reduction
キャラのパッシブ・マスタリー −5% ずつ(ミラ スパートのみ −25/−15/−5/−0) ✅ ActualDelaySkills(9 件)
  • コンボボーナス(2 コンボ以上で ×0.5)は倍率A で、減少値の上限 70% の対象外
  • 用途は 1 秒あたりの火力(DPS) = 合計ダメージ / 中ディレイ。「範囲を取るか火力を取るか」の比較に使う
  • CI(コンボインターバル)は「次に使うスキルの中ディレイの下限」として効く。wiki に値の一覧があるが未収録
  • 前後ディレイ(前隙・後隙)は wiki 自身が「省略」としているので DPS に入れていない

13. 実装への示唆

  • 計算パイプラインは「①能力値計算(§2) → ②カテゴリ集計(同一カテゴリ内は加算、キャップ適用) → ③与ダメージ式(§3、丸め順序込み) → ④段数・追加ダメージ(§5)」の4段
  • 丸めの再現が正確性の肝: []=floor、{}=小数2位切り捨て、割合増加はバフごとに floor
  • バフ・アイテムは「カテゴリ + 数値 + 重複枠」を持つ静的データとしてモデル化する。UI もカテゴリ単位でバフを選ばせる構造が自然
  • wiki 自身が「計算順序未確定・丸め誤差あり」としているため、検証値(実測ダメージ)との突き合わせ機能があると望ましい
  • 入力最小化の観点(UX方針): 約30カテゴリのうちユーザーが都度入力すべきものはほぼ無い。A/B はキャラのステ・装備から、D/E/F はスキル選択から、C/V1/V2/M は敵(狩り場)選択から、L/N/O/P/X 等のバフはキャラに紐づくバフプリセットから自動で埋まる。つまり計算画面の入力は「キャラ・スキル・敵・バフセット」の4つの選択に還元できる。静的データの充実(§9 の未取込ページ)がそのまま入力削減になる
