# Goal: 装備攻撃力の導入(カテゴリ A を実用化する)

状態: **完了(2026-08-22)**

## 目的

攻撃力(カテゴリ A)の「装備攻撃力」項を実装し、登録キャラに装備補正を持たせる。これにより中盤以降の敵(兄弟の鍛冶場 防御 7050 等)で `A+B−C` が負にならず、自分のキャラで現実的な与ダメージが出るようにする(docs/claude/decisions.md「装備なし」の既知制約の解消)。

あわせて、カテゴリ A の `[仮]`(ステ由来係数が旧リポ Excel 値)を wiki 出典に置き換える。

**必ず先に読むこと**: CLAUDE.md、docs/architecture.md、docs/damage-formula.md §4 A、docs/ux-guidelines.md、docs/claude/decisions.md「カテゴリ A(攻撃力)の内訳」。

## wiki 調査結果(取得 2026-08-22)

### 計算式まとめ#BaseAttackPower

- ステータス攻撃力 = Σ(各ステータス × ステータス係数)
- 装備攻撃力 = Σ(各装備補正 × 装備係数)。装備補正は**基本能力値**と**強化能力値**に分かれ、係数が別
  - 基本能力値: エンチャント値を除いた素の装備補正、キャラスキルによる値、アビリティ
  - 強化能力値: エンチャント、テシスコア、アバター強化剤等の期間制能力値、シエナのオーラ
- 基本攻撃力 = `[ステータス攻撃力 + 装備攻撃力] + [装備攻撃力 ÷ 25 × 装備攻撃力強化倍率] × 25`(実装済みの式と一致)
- 装備攻撃力強化倍率 = ストロングウェポン、パワーウェポンなどの合計値

| 依存 | STAB | HACK | INT | MR | 突き(基本/強化) | 斬り(基本/強化) | 魔攻(基本/強化) | 魔防(基本/強化) |
|---|---|---|---|---|---|---|---|---|
| STAB | 2.1 | 1.08 | | | 23.75 / 32.5 | 3.75 / 18.75 | | |
| HACK | 1.08 | 2.1 | | | 3.75 / 18.75 | 23.75 / 32.5 | | |
| STAB+HACK | 1.8 | 1.8 | | | 14.5 / 28.75 | 14.5 / 28.75 | | |
| INT+HACK | | 1.8 | 1.8 | | | 14.5 / 28.75 | 14.5 / 28.75 | |
| INT | | | 2.4 | 0.6 | | | 23.75 / 32.5 | 2.5 / 18.25 |
| MR | | | 0.45 | 2.55 | | | 2.5 / 19.25 | 20.5 / 32.5 |

- ステータス係数は旧リポ `rawStatCoefficients.json` と完全一致 → `[仮]` を外せる
- MR 依存の魔攻強化係数 19.25 は wiki 注記「韓国情報 16.75 と異なるがこの数値で適用」を採用
- 主要でない依存(STAB(熊)、旧 MR、INT+STAB+HACK、INT+STAB、HACK+MR、DEF、銭投げ)は今回対象外(現在の `SkillDependency` 6 種のみ)

### Skill#formula

「計算式まとめ#BaseAttackPower を参照」のみ。独自情報なし。

### 装備システム / 装備システム/装備強化

- 装備強化(+1〜+15)の効果は「武器の追加固定ダメージ」(`追加効果 = INT(INT(補正) × 倍率)`、系統別の補正式あり)。これはカテゴリ A ではなく**追加ダメージ**なので本 goal では扱わない(別 goal)
- 装備攻撃力強化倍率の具体値(パワーウェポン +2%、ストロングウェポン +3〜18%)はこの 2 ページには無い。実装時に `Skill/共通`・`Skill/ティチエル` を確認し、取れなければ `[仮]` で旧 docs の値を使う

## 受け入れ条件

すべて達成(2026-08-22)。確認方法は各項目末尾。

1. **兄弟の鍛冶場で現実的なダメージが出る**: 装備補正を入れたボリスで、与ダメージが下限 1 にならない— 達成: `crates/domain/src/damage.rs` の鍛冶場テスト(装備 default では従来どおり下限 1 の回帰確認も併せて)
2. **トレースに装備の寄与が出る**: `steps_*` の攻撃力(A)の段がステ攻撃力 / 装備攻撃力 / 強化係数の内訳を式文字列と値で示す — 達成: `attack_power_breakdown_steps` の 4 段(テストで段名を確認)
3. **カテゴリ A の `[仮]` 解消**: decisions.md のステ由来係数の `[仮]` を外し出典(計算式まとめ#BaseAttackPower、取得日)を記す。取れない値(強化倍率バフの %)は `[仮]` のまま理由を残す — 達成: 強化倍率も wiki Skill/共通 で取得できたため `[仮]` 無し。残る `[仮]` は装備補正の値域上限 9999 のみ(decisions #4)
4. **キャラ設定に「装備」グループ**: 登録済みキャラの設定列に「装備」アコーディオンが増え、再起動後も残る。wiki から取れる値(係数)は入力させない — 達成: `CharacterSettings.svelte`「装備」アコーディオン。storage は `equipment` 列(v3)。実機確認は docs/screenshots/34〜37(基本 400/400・強化 200/200・PW+SW Lv6 で 極・横斬り × 兄弟の鍛冶場 = min 3,285 / max 3,344 / crit 12,538、装備攻撃力 23,100)
5. `cargo test --workspace`、`cd apps/desktop && npm run build && npx svelte-check` が通る
6. 締めは `finish-goal`(docs/site 再生成まで)— 達成

## スコープ

### 含む

- **domain**: `Equipment`(装備補正 = 突き/斬り/魔攻/魔防 × 基本/強化 の 8 値、装備攻撃力強化倍率)、`EquipmentCoefficients`(依存種別ごとの基本/強化係数)、`equipment_attack_power(&Equipment, &EquipmentCoefficients) -> f64`。`DamageInput::new` の `equipment_attack` / `equipment_enhance_rate` を引数に昇格(コマンドに中立値を書かせない、docs/architecture.md)
- **gamedata**: 依存 6 種 × 装備係数(基本/強化)を `AttackCoefficients` と並べて持つ。出典・取得日をコメントに
- **storage**: `characters` に `equipment TEXT NOT NULL DEFAULT '{}'`(JSON)を追加。既存 DB は `stat_sources` と同じ方式(列の実在を確認して `ALTER TABLE`、`user_version = 3`)
- **UI**(docs/ux-guidelines.md 準拠): 設定列に「装備」グループ。入力は個人差のある値だけ:
  - 装備補正 8 値(突き/斬り/魔攻/魔防 × 基本/強化)を `StatInput` で。初期値 0。ゲーム内ステータス画面の表示値をそのまま写す想定
  - 装備攻撃力強化倍率: バフ選択(パワーウェポン / ストロングウェポン Lv)。取れなければ % 手入力 1 枠
- **docs**: damage-formula.md §4 A の「Skill#formula 未取込」を解消、§9 から該当ページを除去。decisions.md に本 goal の節を追加。status.md 更新

### 含まない(スコープ外、別 goal)

- 装備防御側(カテゴリ J、物理/魔法防御力)、装備強化の追加固定ダメージ、属性、モンスターカード、称号以外のアビリティ、シエナのオーラ(値は「強化能力値」に手入力で含められる)
- 主要でない依存種別(STAB(熊)、旧 MR、複合 3 種、DEF、銭投げ)
- 装備品の個別登録(部位ごとの武器・防具データ)。本 goal は**合計補正値**のみ持つ
