# 装備登録と入力精度の刷新

## 目的

同じ部位の装備を複数登録して即時に切り替えられ、wikiで確定する値を入力せず計算へ使えるようにする。

## 決定

- 部位ごとに登録一覧と選択中IDを持つ。登録全件を検証し、計算は選択中だけ
- 旧JSONはstorage schema v8で登録1件・選択中へ包む
- 基本9値は `values_max` を既定とし、例外編集だけ許可する
- 属性強化は選択属性を対象の実装備へ +9固定。+12以上は等級内上端
- 追加固定ダメージは base+enchant から武器と鎧を合算する
- カタログ外の武器・鎧は補正式の種別だけを選択し、実測固定ダメージは入力しない
- 旧実測固定ダメージは、同じ基本値・エンチャント値で最も近い等級上端へ移行する
- カタログから消えた旧アビリティIDは移行時に除去し、装備以外の編集を妨げない
- 武器アビリティはカテゴリー1・3・4の37件を収録し、最大3枠・同カテゴリー1件で選ぶ。カテゴリー4は段別候補からランダム追加2枠の種類と実測値を保存し、火力・装備補正へ反映する
- 部位一覧・登録切替・候補一覧は装備アイコンを主識別にし、画像未収録だけ `?` を出す
- 登録オーバーレイは背景クリックや候補選択では閉じず、固定ヘッダーの「閉じる ×」か Escape で閉じる。候補選択後は同じ画面でエンチャントとアビリティを編集する
- ボリスの極・連 / 極・残影斬 / 極・氷撃斬は刀 / 太刀 / 大剣へ直接絞り、基本・エンチャント・合計を同じ行に表示する
- 装備補正は S/H/I/M の4枠を先に出し、物防・命中・Cri・回避・敏捷は「その他5補正」に畳む。表示は `合計(+エンチャント)` + アビリティ加算
- 武器アビリティ本体はゲーム内の3枠に対応する「基本補正 / 新装着 / 武器ディレイ」を常設し、プルダウンを使わず候補チップでその場で選ぶ。候補は武器系統で絞った収録全件を効果順に出す。新装着のランダム追加もシエナの能力値スロットと同じく候補チップから足し、`種類 / 実測値 / 外す` の1行を積む。自然回復候補は表示しない
- 装着アビリティは表のある兜・鎧・武器・盾・盾＋・頭・手・足・レリック左右を対象にする。武器3枠、鎧/手/盾＋2枠、その他1枠。カフスとレリックの範囲補正はエンチャントや追加枠へ混ぜず、アビリティ本体の実測値として保存・装備基本値へ合流する。新装着アビリティは全てカテゴリー4で、本体とは別のランダム追加1〜2枠を武器と同じ構造で持つ
- 効果は21周年4系統と22周年スタリオンサイン4色、AFはプシーキー・エクリプス・エーテリアルの主要3段を6依存×通常版/ディフェンシオで揃え、アークロン・コラボを含む45件、レリックは神鳥+1〜+10・ルナリア+1〜+10をペンダント/ブレスレットそれぞれ収録する。AFは主軸スキルの依存能力に合う候補を優先し、特定依存ダメージは一致するスキルにだけ反映する。レリックは直前段階の完成値から当該段階MAXまで成長し、エンチャントを持たない
