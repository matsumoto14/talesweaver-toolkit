状態: **完了(2026-08-24)**

- 装備は部位別 12 スロット(`EquipmentPart`: アイテム参照/カスタム・基本能力値・エンチャント・強化 Lv・追加固定ダメージ上書き・武器アビリティ)になり、装備攻撃力(カテゴリ A)・入場条件は部位集計値で計算される。旧・合計 8 値入力は削除(storage v4 移行で PW/SW のみ引き継ぎ)
- 武器強化の追加固定ダメージ(§5)を実装。トレースに「武器強化(追加固定ダメージ)」段が出る
- キャラタブ「装備」= スロット一覧 → 部位詳細のドリルダウン(v4 モック準拠)。計算タブの装備 knob は PW/SW+武器エンチャントに縮小、候補は部位モデルで表現できるもの(エンチャント上限まで/武器更新)に置換
- 確認: `cargo test --workspace` 139 件 pass、`npm run build && npx svelte-check` 0 errors / 0 warnings、実機スモーク(docs/screenshots/44〜49、全シナリオ OK)。独立レビュー指摘 5 件(要修正 2 / 推奨 2 / テスト不足 1)はすべて対応済み(武器カタログ 4 件の魔防転記誤り、候補適用時のエンチャント clamp+Promise.allSettled、`enhance_added_damage` の値域検証、カスタム武器の文言、weapon_added_damage の分岐テスト)

### スコープ外(次 goal 以降)

- ランダム OP(無条件で火力式に入る OP が wiki に存在しない。称号・新-割合(§5)とまとめて)

### 部位構成(装備システム ページ冒頭の表)

兜 / 鎧 / 武器 / 盾(サブアーム) / 盾+ / 頭 / 体 / 手 / 足 の 9 部位 + 効果(エフェクト) / AF(アーティファクト) / レリック。
**モックの「カフス」は wiki に存在しない**。位置づけ(9 枠目の Show 系補正枠)から wiki の「盾+」に対応する(盾+ = Show装備だが補正が設定されている装備。チャプターアーティファクト、アルカディア・メメントモリ等)。

### エンチャント(装備システム/エンチャント)

- 呪文書 1 回の成功で +4〜20(呪文書の種類による)。対象補正: 突き/斬り/魔攻/魔防/物防(+命中/クリ/回避/敏捷)
- **上限はアイテム個別**(各 Item ページの「上限」行)。対象部位: 兜/鎧/武器/盾/頭/体/手/足/効果/AF(レリック・盾+は不可)
- エンチャント値はゲーム内「強化能力値」に入る(装備攻撃力の強化係数側)

### 装備強化(装備システム/装備強化)

- +1〜+15。**武器の強化のみ追加固定ダメージが発生**(与ダメージ式の外 = docs/damage-formula.md §5)。鎧の強化は最大 HP(火力に効かない)
- 式: `追加効果 = INT(INT(補正) × 倍率)`。**武器は算出値が奇数なら −1**
- 補正 = 武器系統ごとの一次式(**装着アビリティによる補正は含めない**):

| 系統 | 補正式 | 該当武器種 |
|---|---|---|
| STAB系 | 突き×6.67 + 斬り×1.00 | 細剣・短剣・槍・スモールソード・物理銃・クロー・ハンドランチャー |
| STAB+HACK系 | 突き×4.55 + 斬り×4.55 | 長剣・太刀・戦杖・短刀・棒・連接棍 |
| HACK系 | 斬り×6.67 + 突き×1.00 | 刀・斧・鞭・カーラ・物理双剣(+sub)・サイズ・アーミングソード |
| INT系 | 魔攻×6.95 + 魔防×1.05 | 魔杖・ワンド・魔法銃・セプター・トーテム |
| INT+HACK系 | 魔攻×4.55 + 斬り×3.85 | 大剣 |
| MR系 | 魔防×7.70 + 魔攻×0.70 | 聖杖・ハンドベル・魔法双剣(+sub)・ハンマー |

- 倍率(武器): +1=0.4, +2=1.0, +3=1.8, +4=3.0, +5=4.6, +6=6.8, +7=9.6, +8=14.2, +9=20.6, +10=28.8, +11(覚醒)=40.0。**+12〜15 はレンジ内ランダム**(+12=140〜280, +13=300〜460, +14=480〜660, +15=680〜880。再設定呪文書で振り直し可)
- ヒット分割: 攻撃スキル 1 回・1 体あたりの追加ダメージ = `INT(武器の追加ダメージ / 1体あたりのHit数) × Hit数`

### 等級(モックの「最下/下/中/上/最上」)

**wiki に等級という概念は存在しない**。実体は MR(マジックルーレット)= アイテムの基本補正値を Item ページ記載のレンジ内で振り直すシステム。→ 等級はドメインに採用せず、「部位の基本能力値はカタログ既定値(レンジ)を上書きできる」で表現する(追加固定ダメージも実際の補正値から計算するので wiki 式と一致する)。

### アビリティ(装備システム/アビリティ)

部位ごとのカタログ。装備攻撃力(基本能力値)に効くのは武器の 4 系統のみ:
尖った刃(突き +2/3/4/6/7/8/9)・鋭い刃(斬り 同)・知力(魔攻 同)・耐魔力(魔防 同)(段: 下/中/上/N/R/L/E)。
R 以上の追加効果「ダメージ増加+3〜6%」は §5 系のため今回スコープ外。兜のスキル攻撃力+N・鎧研磨(物防)等も火力式の対象外。

### ランダムオプション

武器 OP はすべて条件付き(後方から/ボス限定/確率発動等)の % 追加ダメージ(§5 新-割合、称号と同枠)。**無条件で火力式に入る OP は存在しない** → 期待値でしか計算に反映できないため今回スコープ外(称号・新-割合の goal でまとめて扱う)。モックの「攻撃ダメージ +X%」無条件 OP は架空。

## 決定(設計)

1. **部位は 12 スロット**: `weapon / armor / helm / shield / shield_plus / head / body / hand / leg / effect / artifact / relic`。効果/AF/レリックも装備値(基本能力値)の一部なので部位として持つが、カタログは当面なし(カスタム値のみ)`[仮]`
2. **domain `EquipmentPart`**: `item_id: Option<String>`(カタログ参照。None = 未装備または custom)/ `custom_name: Option<String>`(カタログ外 `[仮]`)/ `base: EquipmentValues`(実測値。カタログ選択時は UI がレンジ中央を既定セット、MR 個人差は上書き)/ `enchant: EquipmentValues`(上限 = カタログ enchant_caps、カスタムは equipment_value_max)/ `enhance_level: u8`(0..=15、weapon/armor のみ >0 可)/ `enhance_added_damage: Option<i64>`(+12 以上の実測表示値の上書き。+11 以下は式で確定するので None 固定)/ `abilities: Vec<String>`(武器アビリティ id)
3. **`Equipment`**: `parts` + 既存の `power_weapon` / `strong_weapon_level`。`base_totals()` = Σ(part.base + アビリティ加算)、`enhanced_totals()` = Σ(part.enchant)。既存 `equipment_attack_power` / `enhance_rate` / 装備係数はそのまま集計値を受ける(合計 8 値の直接入力フィールドは削除、後方互換なし)
4. **武器追加固定ダメージ(§5)を実装**: `weapon_added_damage()` = 系統式(アビリティ除外の武器 base から)× 倍率 → INT×INT、奇数-1。+12〜15 は既定でレンジ下限、`enhance_added_damage` があればそれ。ダメージ結果は per-hit に `INT(追加/hits)` を加算し、トレースに「武器強化(追加固定ダメージ)」段を追加。鎧の enhance_level は記録のみ(HP 未モデル、計算未反映と UI に明記)
5. **gamedata**: `EquipmentItem { id, slot, name, values_min/values_max(4値), enchant_caps(4値), weapon_class: Option<WeaponClass>, source }`。`WeaponClass`(26 種)→ 系統(6 種)対応表と強化倍率表・系統式は全部入れる。アイテム seed は上表(刀・太刀のみ武器収録。他武器種のキャラはカスタム武器で運用 `[仮]`、次 goal で拡充)。武器アビリティカタログ(4 系統×7 段 = 28 件)
6. **storage v4**: `equipment` 列 JSON の構造変更。旧形式(base/enhanced 合計 8 値)からは部位を再構成できないため**合計値は破棄**し、power_weapon / strong_weapon_level のみ引き継ぐ(マイグレーションは「JSON に `parts` キーが無ければ旧形式」で判定)。`PRAGMA table_info` 方式は列追加が無いので不要、user_version を 4 に
7. **入場条件**: `ContentRequirement` の判定を `base_totals()` に追従
8. **UI(キャラタブ)**: 装備ソース = スロット一覧(アイテム名・強化バッジ・突/斬値)→ 部位詳細ドリルダウン(アイテム検索・基本能力値の上書き・エンチャント(上限つき、MAX ボタン)・武器の強化 Lv と追加固定ダメージ・武器アビリティ)。ランダム OP UI は作らない(スコープ外の決定に合わせる)
9. **UI(計算タブ)**: 装備の試し変更 knob は PW/SW + 武器エンチャント程度に縮小し、差分チップは部位単位。candidates は部位モデルで表現できる候補(PW ON / SW Lv6 / 武器と鎧のエンチャントを上限まで / 武器をアビス系列に)に置き換え

## 実装ステップ
