# Goal: キャラ画面を UX ガイドラインに合わせて再構成する

状態: 完了(2026-08-21)。画面構成はその後 character-screen-v2 で置き換え

## 目的

docs/ux-guidelines.md の 4 原則に照らして見つかった違反を解消する。対象は主にキャラ登録・編集と、ダメージ計算画面の調整値の経路。

**必ず先に読むこと**: docs/ux-guidelines.md、CLAUDE.md、docs/architecture.md、docs/claude/goals/2026-08-21-character-stat-sources.md。

## 違反と対応

| # | 違反 | 原則 | 対応 |
|---|---|---|---|
| 1 | 登録フォームに 8 セクション(素ステ/覚醒/ペット/ルーン/クラウン/聖物/バフ/調整値)を詰め込んでいる | 3 | **登録は「名前 + キャラ種」のみ**。素ステは既定値(1)、補正源は中立で登録し、すぐ計算できる。詳細は登録後の「キャラ詳細」で編集 |
| 2 | 全セクションが同じ見た目・同じ重要度で縦に並ぶ | 2 | キャラ詳細を**グループ単位**で構成: 「基本(素ステ・覚醒)」「恒常補正(ペット・ルーン・クラウン・聖物)」「常用バフ」「調整値」。各グループは要約行(現在値の要約、未設定なら「未設定(中立値)」)を常時表示し、編集は展開して行う。一度に開くのは 1 グループ |
| 3 | 素ステを ±Stepper で入力させる | 4 | 素ステは範囲付き自由入力(1–310)にする。覚醒段階・エタ Lv は選択のまま |
| 4 | 計算画面に一時的な調整値の経路がない | 4 | 計算画面に「調整(一時)」の折りたたみを追加: ステごとの固定値/最終固定値の一時加算。キャラには保存せず、計算リクエストにだけ乗せる。ゼロ以外のとき結果側に「調整あり」と表示 |

## 受け入れ条件

1. 名前とキャラ種だけでキャラを登録でき、そのまま計算画面で計算できる(中立値)
2. 登録済みキャラを選ぶと「キャラ詳細」が十分な幅で開き、グループごとに要約 → 展開 → 編集 → 保存ができる。各グループの保存は独立(他グループの未保存変更を壊さない方式なら一括保存でもよい)
3. 未設定のグループは要約行で「未設定(中立値で計算)」と分かる
4. 計算画面の一時調整はキャラデータを変更せず、トレースの補正源内訳に「一時調整」として出る
5. `cargo test --workspace`、`npm run build`、`npx svelte-check` が通る
6. docs/architecture.md のフロント階層、docs/claude/decisions.md、CLAUDE.md 現状を更新

## スコープ外

- 装備・属性・モンスターカードの追加
- 視覚トークンの変更(Main.dc.html の配色・フォントは維持)
- ライト/ダーク切替

## 設計メモ

- Rust 側の変更は最小: `NewCharacter` は `base_stats`/`awakening`/`stat_sources` を省略可能(Default)にするか、フロントで既定値を埋めるかのどちらか。**domain の型は変えない**。計算コマンドに一時調整(`Adjustments` 相当)を任意引数で受け、`StatSources` の調整値と同じ経路で `build_modifiers` に合流させる(domain に新しい概念を増やさない。寄与内訳の表示名で「一時調整」と区別)
- 画面の形(カラム数・部品)は実装者の判断。ガイドラインの「最初の問いと答えが一目で見える」「詳細は開ける位置」を満たすこと
