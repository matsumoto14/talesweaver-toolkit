# Goal: 与ダメージ式の各カテゴリに供給源を配線する

状態: **進行中(2026-08-27)** — キャラスキル・マスタリー・バフ・武器アビリティまで完了。装備アイテム由来が残り

## 目的

与ダメージ式の 36 カテゴリのうち、**自分に効くのに供給源が入っていない**ものを潰す。
「wiki には値があるのに計算に入っていない」= 出る数字が実機より小さい、という状態をなくす。

出典は Tale Wiki `ステータス` の各カテゴリ表(`#z4747f51` ほか)。**この表が
「どのカテゴリに何 % 入るか」を書いた一次ソース**で、上限もここに書いてある。

## 分かったこと(この goal の前提)

### 1. 器が「ステ増加」専用で、効き先を足せなかった

`BuffDefinition::target` は 4 変種すべてステ、`EquipmentAbilityDef::values` は装備攻撃力への
加算固定。だから**同じバフが 2 つのカテゴリに効いていても片方しか入れられなかった**:

| バフ | 能力値 | 与ダメージ | 実装前 |
|---|---|---|---|
| 守護者のためのポーション | 割合増加 +10% | L 最終ダメージ +10% | L が抜けていた |
| クラブSエフェクト | 固定値 +20 | L 最終ダメージ +5% | 同上 |
| ユキダルマン族の特製ポーション | 割合増加 +30% | X1 +20% | X1 が抜けていた |

→ `SkillEffect::Damage { category: DamageCategory, percent }` に一般化し、バフ・
キャラスキル・マスタリー・装備アビリティで**同じ効き先の型を共有**した。
上限はカテゴリ側(`DamageCategory::cap`)が持つので、効き先を足しても上限の処理は増えない。

### 2. カテゴリX は X1〜X6 で上限が違う

1 つの `AttackDamageRate` にまとめていたので、片方が上限に張り付いていてももう片方が
伸びていた。X1(+50%)/ X2(+30%)/ X3(+80%)/ X4(+65%)/ X5(未記載)/ X6(+30%)に分け、
**親 X は「子に上限を掛けてから足した値」**として読み出す。

### 3. wiki のマスタリー節には古い値が混ざる

`Skill/<キャラ>` の「マスタリースキル」節は Ver8.20 前の値が取り残されている行がある
(シベリン【暴走】は性能一覧 +20% に対し節は +60%)。**数値は同じページの
「スキル性能一覧」= カテゴリ表を正とする。**ただし全部が古いわけではない
(ボリス【シルバースカル優勝者】は反映済み)ので、行ごとに突き合わせる。

### 4. アビリティ表には「効果」列と「追加効果」列がある

うちは「効果」列(装備攻撃力)しか取り込んでおらず、**R- 以上に付く追加効果
「ダメージ増加 +3/+4/+6%」= X3 を丸ごと落としていた**。既に持っている装備の分なので
実効的に一番効く穴だった。

## 残っている課題

### A. 装備アイテムそのものの効果に器が無い(次の入口)

`EquipmentItem` に `damage_effects: &[SkillEffect]` を足せば、アビリティと同じ形で入る。

| カテゴリ | 供給源 | wiki 行 |
|---|---|---|
| `X5` | 装備エフェクト +3%、AF「全攻撃ダメージ増加」 | ステータス 1197-1198 |
| `X6` | コラボ装備(武器 +3% / 手 †ゴリラのあーむかばー +5% / エフェクト +3%) | 同 1204-1209 |
| `Old` 攻撃ダメージII | 体装備 †主天使の羽 / †シグマウィング +25% | 同 822-823 |
| `O` 物理/魔法ダメージ増加 | 鎧「リナの服」+3%(1 件だけ) | 同 833 |

### B. アビリティが武器部位にしか付けられない

`Equipment::base_totals` は `parts.weapon.abilities` しか見ない。部位ごとの対応を入れると:

- **手アビリティ**(致命打 / 的中剣)の追加効果「ダメージ増加 +3〜4%」→ `X3`
- **兜アビリティ**(R/L/E-スキル攻撃力増加、スキル攻撃力 +1/+5/+10)→ `E2`
- 鎧アビリティ(鎧研磨・魔法耐性の「防御率 +5〜6%」、ダメージ耐性 +2〜11%)→ 防御側

### C. `W` 攻撃ダメージ(基本発動)(固定値)の供給源が見つかっていない

**器・式・上限(1,000)はすべて揃っている**(`DamageCategory::BasicTriggerDamageFixed`、
`damage.rs` の `… + g(W)`)。足りないのはデータだけ。
ステータス表 1070 行「アビリティ|ダメージ増加|+5〜7,000|武器アビリティ,手アビリティ」は
**`装備システム/アビリティ` のページに載っていない** — アビリティ素材方式 / アイテム方式の
別ページか、装備強化システム由来と思われる。出典が取れるまで未収録。

### D. `T` ダメージ増幅

- 3 コンボ以上のボーナス −10% は実装できる(コンボ数は既に持っている)
- 武器ランダムOP「一定確率で対象が受けるダメージ増加 +10%」は**確率発動**なので
  従来方針どおり `RecordOnly`

### E. 味方スキルは相手のマスタリーを見られない

イスピンの極・エンカレッジはマスタリー【アンパッサン】で攻撃ダメージ +3% が付くが、
同行者が何を取っているかは分からないので入れていない。**「同行者のマスタリー」を
持つかどうかは UX の判断**(入力を 1 つ増やす価値があるか)。

### F. `masteries.rs` の 243 件は数値未検証

マスタリー節から取り込んだままで、性能一覧と突き合わせたのは**モデル済みの 12 件だけ**。
`RecordOnly` の 231 件を計算に入れるときは、note の数値をそのまま使わず必ず突き合わせる。

## 敵側なので触らなくてよいもの

`J` カット率(プレイヤー)・`Q` ダメージ吸収・`R` 被ダメージ倍率・`S` 被ダメージ減少・
`U` ダメージ耐性・`New2` ダメージ緩和・`V2` カット率B・`Y` PVP補正。
どれも「攻撃対象の」値で、対モンスターでは敵データ側に入る。
