# Goal: 残りの補正源(ランダムOP / 称号 / 共通スキル)と上限・クリ率

状態: **計画(2026-08-25)**

## 目的

計算画面に出ている「**未実装の補正源(称号 ・ 等級 ・ ランダムOP)は中立値で計算しています**」を消す。
あわせて、前 goal(docs/claude/goals/2026-08-25-wiki-gaps.md)で別送りにした S7〜S9 を片付ける。

前 goal との違い: あちらは「**すでに画面に出ている** `未実装` / `[仮]` を実値に差し替える」だったのに対し、
こちらは**ドメインに無い補正源を新しく作る**。UI 部品(補正源ペイン)は増える。

出典は Tale Wiki(`talewiki-fetch` skill)。ページの当たりは付けてある(2026-08-25 時点):

| 対象 | ページ | 状況 |
|---|---|---|
| ランダムOP | `ランダムオプション` | 65KB。部位ごとの節(全部位共通 / 兜 / 鎧 / 武器 / サブアーム / 頭 / 体 / 手 / 脚 / レリック(右)(左))+ 転移 |
| 称号 | `称号` / `称号/normal` / `称号/special` / `称号/event` | 本体は概要のみ。実データは normal(221 件)・special(306 件)。列は装備補正 9 値と同じ形 |
| 共通スキル | `Skill/共通` | 17KB。コートアーマー / プロテクトアーマー / オーグメント |
| 極限・ゲージスキル | `Skill/極限` / `Skill/ゲージスキル` | スコープアイ(クリダメ +20〜40%)・エレメンタルパワー(全属性値 +32〜58)・ワイドフォーカス(範囲) |
| 能力値上限 | 取込済み(docs/damage-formula.md §10) | 表はある。適用が未実装 |
| クリティカル率 | 取込済み(§9) | 式はある。対象AGI・対象のクリティカル被撃率が未収録 |

## 段階(それぞれ 1 commit 単位。上から着手する)

### 段階 1 — 「等級」の正体を反映(完了 2026-08-25)

ユーザー指摘で判明: モックの「最下〜最上」は装備の基本補正値の等級ではなく、
**装備強化 +12 以上の追加固定ダメージがレンジのどこに入るか**を指していた
(武器 +12: 140–280 / +13: 300–460 / +14: 480–660 / +15: 680–880)。

- 上書きが無いときの自動計算を**レンジ下限 → レンジ上限**に変更(装備強化再設定呪文書で振り直せるので、
  実用上の想定値は最上値)。決定記録「2026-08-25 装備強化のレンジ倍率」
- 基本補正値の等級は wiki に無い(2026-08-24 の調査どおり)ので `EquipmentPart::base` のレンジ + 上書きのまま
- 計算画面の注記からは「等級」を外す(残りは 称号・ランダムOP)

受け入れ条件: +12〜15 の自動計算がレンジ上限になる / 計算画面の注記が「称号 ・ ランダムOP」だけになる

### 段階 2 — ランダムオプション(S2)

- 取得: `ランダムオプション`(部位ごとの節 + 転移)
- **どのカテゴリに効くのか**を先に分類する。wiki の一覧には 装備補正 9 値に乗るもの、命中P/回避Pに乗るもの
  (「固定回避」「最大回避率」= §7 の最小回避率補正)、与ダメージ式のカテゴリに乗るもの(「物理/魔法ダメージ増加」等)が混ざっている
- 枠数は部位ごとに決まっている(register の「3 枠」は要確認)。枠数と、同じ OP が同部位で重複しない制約を wiki から確定する
- `EquipmentPart` に持たせるか、独立した補正源にするかを決める(部位ごとなら装備側が自然)

受け入れ条件: 主要な部位のランダムOP を選べて、装備値かカテゴリに効く / 効き先が分からない OP は「記録するだけ」と明示 / 計算画面の注記から「ランダムOP」が消える

### 段階 3 — 称号(S3)

**ユーザー確定(2026-08-25)**:

- **装備枠 1 つ**。表示中の 1 件だけが効く(所持ぶんの累積ではない)
- 効き先は**装備の基本能力値への加算**(`EquipmentPart::base` と同じ列)
- **主要称号のみ収録でよい**。527 件(Normal 221 / Special 306、42 グループ)を全部入れる必要はない

wiki の称号表の列は **突き / 斬り / 物防 / 魔攻 / 魔防 / 命中 / 回避 / 敏捷 / Cri** で、
**装備補正 9 値とまったく同じ形**。`EquipmentValues` をそのまま器に使える。

- 取得: `称号/normal`(221 件)、`称号/special`(306 件)。必要なら `称号/event`
- 「主要」の基準を決めて Source に書く(補正値の合計が大きいもの / エンドゲームで実用されるもの)
- 部位は既存 12 スロットに足す形にするか、装備とは別の枠にするかを決める
  (効き先が基本能力値なので装備側が自然。ただし称号にエンチャント・強化・属性強化は無い)
- グループボーナス(N 個完成で +α)は所持状況が要るのでスコープ外。記録に留める

受け入れ条件: 称号を 1 つ選べて、装備の基本能力値に加算される / 計算画面の注記から「称号」が消える(= 注記そのものが消える)

### 段階 4 — 共通スキル(オーグメント込み)と極限スキルの選択(S7)

**共通スキルが補正源として未実装**なのが根本(`StatSources` はペットS / ルーン / クラウン / 神鳥 / 常用バフ / 調整のみ)。

- 取得: `Skill/共通`、`Skill/ゲージスキル`、`Skill/極限`
- **オーグメント込みで調べる**(ユーザー指定)。ストロングウェポン / プロテクトアーマー / ハイパーリミットは
  **Lv2 以降にオーグメント(Lv5)の LvUp が要る**ので、Lv の選択肢がオーグメントに縛られる
- **装備防御力倍率**: コートアーマー(物+18% / 魔+12%)、プロテクトアーマー(Lv1〜6 で 物 36/45/54/63/72/81% ・
  魔 24/30/36/42/48/54%)。値は docs/damage-formula.md §6 の表にある。`EQUIPMENT_DEFENSE_RATE = 1.0` 固定を外す
- **極限スキルの選択が火力を大きく変える**(ユーザー指摘)。`Skill/極限` の表より:

  | スキル | 効果対象 | 基本 | ハイパーリミット Lv1〜6 | 最大値 | 火力への効き |
  |---|---|---|---|---|---|
  | スコープアイ | クリティカルダメージ増加 | +20% | +7〜+17 | +40% | **カテゴリ G** |
  | エレメンタルパワー | 全属性値 | +32 | +11〜+21 | +58 | **カテゴリ I**(属性差) |
  | ワイドフォーカス | スキル範囲 | +4 | +4〜+14 | +20 | 火力には効かない(範囲) |
  | フルスロットル | 中ディレイ / 単体チャネリング段数 | ×75% | −7〜−17 / +0〜+3 | ×55% / +3 | 段数が増えるものがある |
  | オーバードライブ | 武器ディレイ | ×75% | −10〜−20 | ×50% | DPS(1 発の火力ではない) |

  - **どれか 1 つを選ぶ排他なのか、複数同時に乗るのかを wiki / 実機で確定する**(ユーザーの
    「範囲を取るか火力を取るか」という言い方からは排他に見える)
  - スコープアイは G(クリティカルダメージ増加)なので、非クリティカル時には乗らない(§4 の F×G)
  - エレメンタルパワーは属性値の供給源が 1 つ増えることになる。既存の 200(装備 90 + 供給源 110)に
    足すと 255 の上限に当たる可能性がある
- 共通スキルには最大HP/MP の固定増加やパワーウェポン / ストロングウェポン(既に装備側にある)も含まれる。
  **今回のスコープは 装備防御力倍率 と 極限スキルの選択(G / I に効くもの)まで**にして、他は記録に留める

受け入れ条件: 共通スキル(オーグメント Lv 込み)と極限スキルを選べる / 防御タブの防御力が倍率で動く / スコープアイでクリティカル時のダメージが増える / エレメンタルパワーで属性値が増える / リンゴの島・ベリネンルミでは装備防御力倍率が 100% 固定になる注記が出る

### 段階 5 — 最終能力値への上限適用(S8)

- 上限値は取込済み(docs/damage-formula.md §10。覚醒段階 + エタの意志 Lv で 1,500〜2,400)
- いまは `effective_stats` に覚醒段階が届いていないので適用していない。`stat_sources` の経路に覚醒を通す
- 上限に当たったら**捨てられた分**を出す(段階4 のダメージ上限・防御力上限と同じ出し方)

受け入れ条件: 最終能力値が上限で頭打ちになる / ステトレースに「上限で捨てられた分」が出る

### 段階 6 — クリティカル率(S9)

- 式は取込済み(docs/damage-formula.md §9)。**スキルの Cri値は S5 で収録済み**、装備クリティカル補正は段階2(前 goal)で入った
- 足りないのは **対象のAGI** と **対象のクリティカル被撃率**。`狩り場情報一覧` に値がある敵とない敵(`?`)が混在する
- `Enemy` に `agi` / `critical_taken_rate` を足し、**値がある敵だけ**クリティカル率を出す(無い敵は出さない)
- 表示先は計算タブの「クリティカル ×N」の横(期待値が読めるように)

受け入れ条件: 値のある敵でクリティカル率が出る / 値の無い敵では出さない(0% と混同させない)
