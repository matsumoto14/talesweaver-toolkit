# Goal: v4 UI 全面刷新(タブ+キャラレール構成への移行)

状態: **実装済み・実機検証中(2026-08-24)**

## 目的

デザインモック「TW Toolkit Prototype v4」(claude.ai/design プロジェクト「Repo UI mockup directions」)を、実データ(domain / gamedata / storage)で動く形でアプリに実装する。モックの仮データ(架空のコンテンツ数値・部位別装備)は転記せず、現行モデルで表現できる範囲を実装し、足りない静的データは `[仮]` として最小限だけ足す。

## 受け入れ条件

1. 上部タブ「ホーム / ダメージ計算 / キャラ」+ 左キャラレール(クリア数表示・登録導線)で全機能に到達できる
2. ホーム: コンテンツ到達一覧(火力目安と入場条件の判定は Rust 側 `evaluate_contents`)・お気に入り・「次に変えるなら」(候補は `preview_damage` で再計算)
3. ダメージ計算: 対象/スキル選択 → 1発(最大)・合計・クリティカル → もし〜だったら → なぜこの数字?(攻撃力の内訳 / 防御を抜く / 倍率で伸ばす + 詳細トレース)。試し変更(保存前プレビュー)と「キャラに保存」
4. キャラ: 名前+キャラ種のみの登録(コピー登録つき)・補正源ドリルダウン編集・いまの実力シート
5. `cargo test --workspace`・`cd apps/desktop && npm run build && npx svelte-check` 全通過
6. 実機スモークテスト(docs/screenshots/40〜43)
