# ADR-003: 敵・コンテンツカタログとデータ出典

- ステータス: 採用
- 期間: 2026-08-24〜2026-08-25
- 元文書: goals/2026-08-24-contents-expansion.md(git 履歴参照)

## 背景

敵カタログ(`crates/gamedata/src/enemies.rs`)とコンテンツカタログ(`contents.rs`)を空(敵 3 体・2 エリア 3 件)から実データ化する必要があった。旧リポ `twtoolkit` のモンスターデータ、wiki「狩り場情報一覧」、swiki「コンテンツ入場条件」、ユーザー提供の実測表という 4 系統の出典があり、値が重複・矛盾する箇所をどう裁くかが論点だった。

## 決定

- **敵データの出典の格付け: 実測表「モンスター能力値リスト」を最終正とし、wiki 狩り場情報一覧は値の裏取り(カット率・防御力の一致確認)専用、旧リポ monsters.json は初期シードに位置づける**
- **防御力は「ステータス防御+固定防御」に分解される。既存 28 体は合算値が実測表と全一致(例: キシニク(EX) 1500+118050)**
- **被害減少の実値は 0 / 2925 / 3250 / 4550 / 5850 の 5 段。wiki の「6500 固定と思われる」という推測は不採用**
- **最後の決戦2 のカット率は 3 ソース中唯一の差分。実測表の 70%(0.30)を採用**
- **収録範囲は実測表の実データ全件に統一。wiki 狩り場情報一覧にしか無い 5 体(プシーキーの虚像・マーキュリアル洞窟ボス・アビスボスN/H・次元の隙間)は被害減少が不明(0 `[仮]`)なため削除(ユーザー決定)。最終的に敵 42 体**
- **HP(ソロ)は実測表に全件あるが未収録。到達判定は per-hit 目安のみで hp を消費する機能が無い(YAGNI)。必要になったら追加する**
- **リンゴボスはルミナスと推定(カット率 -48% 一致、防御 8700=1800+6900 で整合)だが確証が無いため旧リポ名のまま保持**
- **コンテンツ入場条件は swiki「コンテンツ入場条件」(<https://erumisutoburvip.swiki.jp/>)を正とし、4 エリア 59 件に再構成**
- **装備条件は `ContentRequirement::EquipmentBySkill { single, mr, composite }` の単一条件にした。表の S/H/I・M・複合列は「使うスキルの依存種別によって比較先が決まる」ものであり、3 条件を AND で並べると全部満たさないと通らない嘘になり、OR で並べると無関係な行が UI に出る**
- **旧 `EquipmentThrust` / `EquipmentThrustSlash` は削除し `AwakeningStage` を追加(後方互換を残さない)**
- **敵データが無いコンテンツ(神鳥の塒・ルミナスEX・混乱した大地等)も到達一覧に載せる(ユーザー決定)。`enemy_id` / `need_per_hit` は `Option` にし、None なら入場条件のみで判定する**
- **判定できない条件(ルーンレベル・共通スキルコンプ・コア・カフス上限・前提クリア)は `entry_note` に表示専用で保持する。キャラモデルに値が無く、条件化すると「常に未達」か「常に無視」の嘘になるため**
- **`required` が 0 の装備条件はチェックを生成しない(表の "-" は「その系統は条件なし」の意)**
- **計算タブの対象一覧は `enemy_id` を持つコンテンツだけに絞る(選べても計算できない対象を出さない)**
- **ゆがんだ村の対応(ユーザー確認): 追従する喜び = レイティア、見つめる悲しみ = 設計者**
- **`need_per_hit` の `[仮]` は「コミュニティ知識」に読み替える。wiki 狩り場情報一覧に目安ダメージの列自体が無く、再取得しても埋まらないため**
- **wiki にしか無い敵(空虚の領域・次元の隙間・ヴェスティージ一般・プシーキーの虚像等)はデータが揃っていても収録しない。収録するとコンテンツ側(入場条件・目安)の追加作業が別途必要になるため**
- **武器ダメージ無効(キマイラ)は `[仮]` のまま(wiki 狩り場情報一覧に該当列が無い)**
- **wiki にあって未消費の列(必中命中P・敵AGI・クリティカル被撃率・被ダメージ倍率 I/II/XXX・カット率B)はフィールドを先に足さない。消費側(プレイヤーの命中P・クリティカル率・敵ごとの倍率枠)が無いため**

## 却下した選択肢

- 装備条件を単体/魔法/複合の 3 条件に分けて AND または OR で並べる → 単一条件 `EquipmentBySkill` に統合(上記参照)
- 敵データが無いコンテンツを到達一覧から除外する → ユーザー決定で一覧に残し、入場条件のみで判定する形にした

## 経緯

- 敵カタログは段階的に拡充した: 旧リポ 28 体 → wiki 裏取り済み 5 体を追加(33 体)→ ユーザー提供の実測表で 14 体追加・被害減少の `[仮]` 解消(47 体)→ wiki のみの 5 体を削除して 42 体に確定
- コンテンツカタログも同様に置き換わった: 当初は wiki 節構成ベースの 8 エリア 33 件で入場条件はほぼ不明のまま `[仮]` だったが、swiki 出典への切替で 4 エリア 59 件・入場条件を実データ化する形に再構成された
- 2026-08-25 に wiki を再取得して敵 42 体を再照合し、全件一致を確認(最後の決戦2 のカット率のみ実測表 70% を維持)。`ENEMIES_SOURCE` の出典順を wiki 先頭に、取得日を 2026-08-25 に更新した
